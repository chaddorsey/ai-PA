5. **Selective Operations**: Apply hierarchy changes to specific branches

- `extra-files/omnifocus-mcp.omnijs` (added 5 advanced hierarchy operation methods):
  - `flattenTaskHierarchy()` - Convert hierarchical tasks to flat structure
  - `moveTaskBranch()` - Move entire task branches with all descendants
  - `nestTasksAsHierarchy()` - Convert flat tasks to hierarchical structure
  - `restructureTaskHierarchy()` - Execute multiple operations in sequence
  - `previewHierarchyOperation()` - Preview operation effects without execution

  - `moveTaskBranch` - MCP tool for branch movement

  - `restructureTaskHierarchy` - MCP tool for complex restructuring
  - `previewHierarchyOperation` - MCP tool for operation preview
