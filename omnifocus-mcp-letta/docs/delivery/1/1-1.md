## Description

Implement complete end-to-end `listTasksByTag` functionality by creating both the OmniFocus plugin method and registering it as an MCP tool in the server. This enables AI-driven tag-based task queries through Claude Desktop conversations, allowing users to ask questions like "Show me all tasks tagged @Urgent" through natural language interaction.

The implementation extends the existing plugin library with a new method that leverages OmniFocus's `flattenedTags` collection, then registers it as an MCP tool with comprehensive parameter validation and error handling.

## Requirements

### Functional Requirements

**Plugin Implementation:**
1. **Tag-based Filtering**: Accept a `tagId` parameter and return all tasks associated with that tag
2. **Optional Parameters Support**:
   - `includeCompleted`: Boolean to control whether completed tasks are included (default: false)
   - `projectId`: Optional string to scope results to a specific project
3. **Data Consistency**: Return tasks in the same serialized format as existing `listRemaining` and `listTasksByProject` methods
4. **Error Handling**: Gracefully handle invalid tag IDs and return appropriate error messages
5. **Performance**: Execute efficiently even with large tag collections

**Server Registration:**
6. **MCP Tool Registration**: Register `listTasksByTag` as an MCP tool with proper metadata
7. **Schema Definition**: Create comprehensive Zod schema for parameter validation
8. **Documentation**: Provide clear tool description for AI understanding
9. **Response Formatting**: Format responses using established `asJsonText` helper

### Non-Functional Requirements
1. **Response Time**: Complete filtering operations within 200ms for typical datasets
2. **Memory Usage**: Minimal memory overhead during filtering operations
3. **API Consistency**: Follow same parameter and return value patterns as existing plugin methods

### Technical Requirements
1. **Integration**: Seamlessly integrate with existing `omnifocus-mcp.omnijs` library structure
2. **Validation**: Validate tag ID existence before attempting to filter tasks
3. **Serialization**: Use existing `serializeTask` function for consistent output format
