# 1-14 Add exclusion filters to queryTasks and searchTasks

[Back to task list](./tasks.md)

## Description

Implement exclusion filter parameters in both `queryTasks` and `searchTasks` methods to enable negative filtering. This enhancement will eliminate multi-step query operations by allowing users to exclude specific projects, tags, or folders directly in a single API call.

This addresses the real-world problem where queries like "Show me active tasks that include 'DSE' but are not in my Priorities for the Week project" currently require two API calls and client-side filtering.

## Requirements

### Functional Requirements
1. **Project Exclusion**: Add `excludeProjectIds: string[]` parameter to filter out tasks from specific projects
2. **Tag Exclusion**: Add `excludeTagIds: string[]` parameter to filter out tasks with specific tags
3. **Folder Exclusion**: Add `excludeFolderIds: string[]` parameter to filter out tasks from project folders
4. **Multiple Exclusions**: Support combining multiple exclusion types in single query
5. **Efficient Filtering**: Implement exclusion logic within existing filter loops for optimal performance

### Non-Functional Requirements
1. **Performance**: Exclusion filtering adds < 100ms to query processing time
2. **Memory Efficiency**: Exclusion filtering doesn't significantly increase memory usage
3. **Backward Compatibility**: Existing queries without exclusion parameters work unchanged

### Technical Requirements
1. **OmniFocus Integration**: Use existing project/tag/folder relationship APIs
2. **Cache Compatibility**: Exclusion parameters properly integrated with cache key generation
3. **Error Handling**: Invalid exclusion IDs handled gracefully with clear error messages

## Implementation Plan

### Phase 1: Plugin Implementation (queryTasks)
1. **Add exclusion parameters** to `queryTasks` method:
   ```javascript
   // New parameter destructuring
   const { excludeProjectIds = [], excludeTagIds = [], excludeFolderIds = [] } = params;
   ```

2. **Implement exclusion logic** in filtering loop:
   ```javascript
   // Project exclusion check
   if (excludeProjectIds.length > 0 && t.project && 
       excludeProjectIds.includes(bareId(t.project.id))) continue;
   
   // Tag exclusion check  
   if (excludeTagIds.length > 0 && t.tags.some(tag => 
       excludeTagIds.includes(bareId(tag.id)))) continue;
   
   // Folder exclusion check (via project folder hierarchy)
   if (excludeFolderIds.length > 0 && t.project && t.project.folder &&
       isInExcludedFolder(t.project, excludeFolderIds)) continue;
   ```

3. **Add folder hierarchy helper**:
   ```javascript
   function isInExcludedFolder(project, excludeFolderIds) {
     let folder = project.folder;
     while (folder) {
       if (excludeFolderIds.includes(bareId(folder.id))) return true;
       folder = folder.parent;
     }
     return false;
   }
   ```

### Phase 2: Plugin Implementation (searchTasks)
