## Description

Implement advanced boolean logic for tag filtering in both `queryTasks` and `searchTasks`. This enables complex tag combinations using AND, OR, and NOT operations, allowing users to express sophisticated filtering requirements like "tasks with (@work AND @priority) but NOT @waiting" or "tasks with (@home OR @errands)".

## Requirements

### New Parameter Structure

#### **Tag Combination Object**
Replace the current simple `tagId` parameter with a flexible `tagCombination` object:

```typescript
tagCombination: {
  and?: string[];     // All of these tags must be present
  or?: string[];      // At least one of these tags must be present  
  not?: string[];     // None of these tags can be present
  any?: string[];     // Legacy: equivalent to 'or' for backward compatibility
}
```

### Use Cases and Examples

#### **Common Scenarios**
```javascript
// Work tasks that are high priority but not waiting
queryTasks({ 
  tagCombination: { 
    and: ['@work', '@high-priority'],

  }

// Home or errands tasks available today
```

## Implementation Strategy

### **Step 1: Tag Matching Helper Function**
```javascript
function matchesTagCombination(task, tagCombination) {
  if (!tagCombination) return true;
  
  const taskTagIds = new Set(task.tags.map(tag => bareId(tag.id)));
  
  // AND logic: ALL specified tags must be present
  if (tagCombination.and && tagCombination.and.length > 0) {
    if (!tagCombination.and.every(tagId => taskTagIds.has(tagId))) {
      return false;
    }
  }
  
  // OR logic: AT LEAST ONE specified tag must be present
  if (tagCombination.or && tagCombination.or.length > 0) {
    if (!tagCombination.or.some(tagId => taskTagIds.has(tagId))) {
      return false;
    }
  }
  
  // Legacy 'any' support (equivalent to OR)
  if (tagCombination.any && tagCombination.any.length > 0) {
    if (!tagCombination.any.some(tagId => taskTagIds.has(tagId))) {
      return false;
    }
  }
  
  // NOT logic: NONE of the specified tags can be present
  if (tagCombination.not && tagCombination.not.length > 0) {
    if (tagCombination.not.some(tagId => taskTagIds.has(tagId))) {
      return false;
    }
  }
  
  return true;
}
```

### **Step 2: Validation Helper**
```javascript
function validateTagCombination(tagCombination) {
  if (!tagCombination) return [];
  
  const allTagIds = [
    ...(tagCombination.and || []),
    ...(tagCombination.or || []),
    ...(tagCombination.any || []),
    ...(tagCombination.not || [])
  ];
  
  // Validate that all tag IDs exist
  const invalidTags = [];
  for (const tagId of allTagIds) {
    const tag = flattenedTags.find(t => bareId(t.id) === tagId);
    if (!tag) {
      invalidTags.push(tagId);
    }
  }
  
  return invalidTags;
}
```

### **Step 3: Enhance queryTasks**
Add tag combination filtering after existing filters:

```javascript
// Tag combination filtering (replaces simple tagId logic)
if (params.tagCombination) {
  // Validate tag IDs first
  const invalidTags = validateTagCombination(params.tagCombination);
  if (invalidTags.length > 0) {
    throw new Error(`Invalid tag IDs: ${invalidTags.join(', ')}`);
  }
  
  if (!matchesTagCombination(t, params.tagCombination)) continue;
} else if (params.tagId) {
  // Legacy single tag support for backward compatibility
  if (!t.tags.some(taskTag => bareId(taskTag.id) === params.tagId)) continue;
}
```
