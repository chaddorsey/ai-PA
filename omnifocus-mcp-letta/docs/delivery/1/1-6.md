## Implementation Plan

### Phase 1: Schema Definition
1. **Create comprehensive Zod schema**:
   ```typescript
   const createTaskSchema = z.object({
     name: z.string().describe("Task name"),
     projectId: z.string().optional().describe("Project UUID to assign task to"),
     tagIds: z.array(z.string()).optional().describe("Array of tag UUIDs"),
     note: z.string().optional().describe("Task notes/description"),
     deferDate: z.string().optional().describe("ISO date string for defer date"),
     dueDate: z.string().optional().describe("ISO date string for due date"),
     flagged: z.boolean().optional().describe("Whether task is flagged")
   });
   ```
