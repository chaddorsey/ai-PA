## Requirements
- Implement `listUncompletedTasks` handler with optional filters (`projectId`, `onlyFlagged`, `onlyAvailable`).
- Implement `listProjects` handler with optional switches (`folderId`, `listProjectNames`, `listByFolder`).
- Ensure outputs include required metadata (IDs, names, flagged status, dates, task IDs).
- Reuse existing serializers for task/project metadata where possible to avoid duplication.
- Handle absence of optional data gracefully (e.g., missing due date).
- Provide folder-grouped responses when requested while preserving flat list as default.
