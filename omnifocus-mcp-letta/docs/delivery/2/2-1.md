## Description

Implement the `listInbox` method in the OmniFocus plugin (`omnifocus-mcp.omnijs`) to provide comprehensive inbox listing capabilities with filtering options. This method will enable AI assistants to access and understand the current inbox state for conversational processing workflows.

The inbox is a core OmniFocus concept where new tasks and ideas are captured before being processed (assigned to projects, tagged, scheduled, etc.). This method provides the foundation for inbox processing workflows.

## Requirements

### Functional Requirements
1. **Basic Inbox Listing**: Return all items currently in the inbox with full task metadata
2. **Completion Filtering**: Optional parameter to include/exclude completed inbox items
3. **Limit Support**: Optional parameter to limit number of results for performance
4. **Metadata Inclusion**: Include all standard task fields (name, note, dates, tags, etc.)
5. **Performance Optimization**: Efficient handling of large inboxes (500+ items)

### Non-Functional Requirements
1. **Response Time**: Complete within 300ms for up to 500 inbox items
2. **Memory Efficiency**: Minimal memory overhead for inbox data processing
3. **Consistency**: Use existing task serialization for uniform data format
4. **Error Handling**: Graceful handling of inbox access issues

### Technical Requirements
1. **API Integration**: Use OmniFocus JavaScript automation API to access inbox
2. **Serialization**: Leverage existing `serializeTask()` function for consistency
3. **Parameter Validation**: Validate optional parameters (includeCompleted, limit)
4. **Caching Integration**: Prepare for future caching optimizations
