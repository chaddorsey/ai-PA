## Requirements

### Functional Requirements
1. **getProjectHierarchy**: Return flat list of all projects with folder path context
2. **getProjectTree**: Return nested tree structure showing complete project organization
3. **Performance**: Handle large project lists efficiently without blocking
4. **Completeness**: Include all project states (active, on hold, completed, dropped)
5. **Context**: Provide sufficient metadata for AI understanding of organization

### Technical Requirements
1. Leverage existing folder and project listing capabilities
2. Implement efficient tree construction algorithms
3. Cache hierarchy data for performance
4. Integrate with existing caching mechanisms
5. Provide both summary and detailed views

### API Requirements
```typescript
// Flat hierarchy with path context
getProjectHierarchy({
  includeCompleted?: boolean,
  includeDropped?: boolean,
  maxDepth?: number
}) -> ProjectHierarchyItem[]

// Nested tree structure  
getProjectTree({
  includeCompleted?: boolean,
  includeDropped?: boolean,
  foldersOnly?: boolean
}) -> ProjectTreeNode
```
