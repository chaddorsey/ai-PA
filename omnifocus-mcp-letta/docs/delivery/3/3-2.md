## Requirements

### Core Functionality
1. **~~duplicatePerspective~~**: ❌ **REMOVED - API Limitation**
   - OmniFocus automation API does not support perspective creation
   - Cannot implement perspective duplication programmatically

2. **setActivePerspective**: Enhanced perspective switching with validation:
   - Switch to perspective with confirmation
   - Validate perspective exists before switching
   - Handle perspective activation errors gracefully
   - Return detailed activation status
   - Enhanced error reporting beyond basic switchToPerspective

3. **getPerspectiveUsage**: Analyze perspective usage patterns:
   - Track perspective switch frequency
   - Identify most/least used perspectives
   - Provide usage analytics for optimization
   - Support time-based usage analysis
   - Generate perspective usage insights

4. **validatePerspectiveConfig**: Configuration validation for existing perspectives:
   - Verify filter criteria are valid for existing perspectives
   - Check tag/project references exist in current OmniFocus database
   - Validate view configuration compatibility
   - Provide detailed validation reports for perspective health checks

### Technical Requirements
- Build on the CRUD operations from task 3-1
- Integration with existing perspective switching functionality
- Robust error handling for edge cases
- Performance optimization for duplication operations
- Validation of perspective configurations before activation

### User Experience Requirements
- Intuitive duplication with smart defaults
- Clear feedback on perspective operations
- Graceful handling of invalid perspective states
- Helpful suggestions for perspective improvements
