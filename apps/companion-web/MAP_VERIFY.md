# MAP_VERIFY — Manual Verification Steps

Quick guide to visually confirm the map layer (Pillar 1) works in the dev server.

## Prerequisites

1. Bundle exists at `tools/amtrak-position-engine/bundles/leg58/bundle.json`
2. `companion-core` is built: `cd packages/companion-core && npm run build` (if needed)
3. Dev server is not running

## Start the dev server

```bash
cd apps/companion-web
npm run dev
```

Open `http://localhost:5173` in a browser.

## Step 1: Map renders

- Expect: A gray/cream background map (no tile data yet — PMTiles corridor file is a
  placeholder until Plan 1 pipeline runs `pmtiles extract`).
- Expect: No JavaScript console errors about "WebGL" or "map container".

## Step 2: Route polyline

The Trip/Map home page mounts `TripMap.svelte`. Once `appState.bundle` is loaded:

- Expect: A blue route line (opacity 0.85, width 4px) following the leg 58 geometry
  (New Orleans → Chicago corridor).
- If no line appears, check the browser console for errors loading the bundle.

Load the bundle manually in the console:

```js
import { appState } from '/src/lib/core/AppState.svelte.js';
import bundle from '/tools/amtrak-position-engine/bundles/leg58/bundle.json' assert {type:'json'};
appState.bundle = bundle;
```

## Step 3: Station pins

After bundle loads:

- Expect: Small white circles with blue border appear at each station lat/lon.
- Count: There should be 18 station pins for leg 58 (NOL → CHI).
- Tap/click a pin → browser console should log the station code (or trigger the
  `stationSelect` callback if wired to `+layout.svelte`).

## Step 4: Position marker + uncertainty band

Set a simulated position in the console:

```js
appState.position = {
  mile: 30,
  lat: 30.2,
  lon: -90.3,
  source: 'gps',
  direction: 1,
  leg: '58',
  stopped: false,
};
```

- Expect: A solid blue circle (10px radius, white stroke) appears near mile 30.
- Expect: Map `easeTo` animates toward the position.

For the P10-P90 band, set source to `'predicted'`:

```js
appState.position = { ...appState.position, source: 'predicted' };
```

- Expect: A semi-transparent light-blue band segment appears on the route, centered
  around mile 30, spanning approximately ±5 miles along the track.
- The band should follow the track geometry (curved where the route curves), NOT a
  horizontal ±lon offset.

For off-route style:

```js
appState.position = { ...appState.position, source: 'off-route' };
```

- Expect: Position marker becomes gray/muted (opacity 0.5).

## Step 5: Tab navigation (no duplicate layers)

Navigate to the Companion tab and back to the Trip/Map tab.

- Expect: No duplicate layers or console errors about "layer already exists".
- Expect: Map is still responsive after returning.

## Step 6: Build check

```bash
npm run build
```

- Expect: Build completes with no errors.
- The PMTiles corridor source will 404 in production until the actual `.pmtiles`
  file is generated by Plan 1's `pmtiles extract` pipeline task.
