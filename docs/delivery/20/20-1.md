## Requirements
- FastAPI service code hosted in dedicated directory `slack-analytics-mcp-server` (or equivalent) with clear entrypoint.
- Docker image includes required Playwright/Chromium dependencies for Slack export automation.
- Service exposes `/health` and `/trigger-export` endpoints on port `8087`.
- docker-compose configuration adds service to `pa-internal` network with health check and necessary environment variables.

## Implementation Plan
1. Copy/refine `slack_analytics_endpoint.py` into new service package structure with appropriate module layout.
2. Author Dockerfile leveraging multi-stage build similar to Calendly service, installing dependencies and Slack scripts.
3. Mount or bake required Slack automation scripts and auth artifacts; define volume strategy in docker-compose.
4. Add service entry to `docker-compose.yml`, including health check and network configuration.
5. Provide environment variable defaults and README snippet if needed for service configuration.

## Test Plan
- Build container locally using `docker compose build slack-analytics-mcp-server`.
- Run `docker compose up slack-analytics-mcp-server` and confirm health check passes.
- Send POST request to `/trigger-export` with test payload (possibly mocked script execution) and verify 200 response.
- Validate logs capture successful command invocation or meaningful errors for missing auth state.

## Verification
- Compose build and up commands succeed without errors.
- Health endpoint returns JSON `status: healthy`.
- Trigger endpoint returns success JSON when provided with valid Slack auth context, or descriptive error otherwise.
