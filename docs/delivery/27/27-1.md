## Requirements

1. Poll ESPN API for NFL, NBA, MLB, NHL, NCAA Football, NCAA Basketball, MLS
2. Cache game data with team/league indexing
3. Provide REST endpoints: /health, /games, /team/<name>, /channel/<network>, /lookup
4. Load channel mapping from JSON configuration
5. Background thread for periodic updates (15 min default)
