# [3-5] Add project group type management

[Back to task list](./tasks.md)

## Description

Implement project group type management functions that allow reading and setting whether project tasks complete in parallel (independently) or sequential (dependency chain) mode. This provides granular control over task completion workflows within projects.

## Requirements

### Core Functionality
1. **getProjectGroupType**: Read the current group type for a project
   - Returns 'parallel' or 'sequential' based on project.sequential property
   - Include project validation and error handling
   - Support lookup by project name or ID

2. **setProjectGroupType**: Set the group type for a project  
   - Accept 'parallel' or 'sequential' values
   - Map to project.sequential boolean property (false = parallel, true = sequential)
   - Validate project exists and is accessible
   - Provide confirmation of change

### Technical Requirements
- Use existing project lookup patterns from previous implementations
- Follow established error handling and validation patterns
- Integration with OmniFocus project.sequential property [[memory:951370812481159986]]
- Proper caching for performance optimization

### Data Integrity Requirements
- Validate project exists before modification
- Handle read-only or protected projects gracefully
- Ensure group type changes don't break existing task relationships
