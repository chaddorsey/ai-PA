## Tool Specifications

### Project Group Type Tools
```typescript
getProjectGroupType: {
  description: "Get the group type (parallel/sequential) for a project's tasks",
  parameters: {
    projectName?: string,
    projectId?: string
  }
}

setProjectGroupType: {
  description: "Set whether project tasks complete in parallel or sequential order",
  parameters: {
    projectName?: string,
    projectId?: string,
    groupType: "parallel" | "sequential"
  }
}
```

### Project Completion Behavior Tools
```typescript
getProjectCompletionBehavior: {
  description: "Get whether a project auto-completes with last task or requires manual completion",
  parameters: {
    projectName?: string,
    projectId?: string
  }
}

setProjectCompletionBehavior: {
  description: "Set project completion behavior (auto-complete or manual)",
  parameters: {
    projectName?: string,
    projectId?: string,
    completionBehavior: "completeWithLastAction" | "manual"
  }
}
```

### Task Group Type Tools
```typescript
getTaskGroupType: {
  description: "Get the group type for a parent task's subtasks",
  parameters: {
    taskName?: string,
    taskId?: string
  }
}

setTaskGroupType: {
  description: "Set whether subtasks complete in parallel or sequential order",
  parameters: {
    taskName?: string,
    taskId?: string,
    groupType: "parallel" | "sequential"
  }
}
```
