### Phase 2: CRUD Tool Registration
1. **Register getPerspective**:
   - Parameter: perspective ID or name
   - Response: complete perspective configuration
   - Error handling for non-existent perspectives

2. **Register createPerspective**:
   - Parameters: name, configuration, filter rules, view settings
   - Response: created perspective details with ID
   - Validation for all configuration parameters

3. **Register updatePerspective**:
   - Parameters: perspective ID, partial configuration updates
   - Response: updated perspective details
   - Protection against built-in perspective modification

4. **Register deletePerspective**:
   - Parameters: perspective ID, optional confirmation flags
   - Response: deletion confirmation and cleanup details
   - Safety checks for built-in perspectives and active perspective

### Phase 3: Advanced Tool Registration
1. **Register duplicatePerspective**:
   - Parameters: source perspective ID, new name, configuration overrides
   - Response: duplicated perspective details
   - Support for template-based duplication

2. **Register setActivePerspective**:
   - Parameters: perspective ID/name, validation options
   - Response: activation status and current perspective info
   - Enhanced error handling beyond basic switchToPerspective

3. **Register getPerspectiveUsage**:
   - Parameters: time range, analysis options
   - Response: usage statistics and analytics
   - Performance optimization for large datasets

4. **Register validatePerspectiveConfig**:
   - Parameters: perspective configuration to validate
