# [25-6] Implement update event tool

## Description
Implement `update_calendar_event()` tool to modify existing calendar events. Support partial updates where only provided fields are updated, preserving all other event properties.

## Requirements

1. **Function**: `update_calendar_event()` with parameters:
   - `calendar_id` (str, required): Calendar ID (email) or "primary"
   - `event_id` (str, required): Event ID of event to update
   - All event property parameters (optional):
     - `summary` (str, optional): New title
     - `start_datetime` (str, optional): New start datetime (ISO 8601)
     - `end_datetime` (str, optional): New end datetime (ISO 8601)
     - `timezone` (str, optional): Timezone for datetime fields
     - `description` (str, optional): New description
     - `location` (str, optional): New location
     - `attendees` (List[str], optional): New attendees list (replaces existing)
     - `attachment_file_ids` (List[str], optional): New attachments list (replaces existing)

2. **Update Strategy**:
   - First retrieve existing event using `events.get()`
   - Update only provided fields (partial update)
   - Preserve all other fields from existing event
   - Use `events.update()` method with full event body

3. **Response Format**:
   - Updated event object with full details
   - Status indicator (success/error)
   - Error message if failed

4. **Error Handling**:
   - Handle event not found
   - Handle invalid event ID
   - Handle permission errors (no write access)
   - Handle invalid parameter values
   - Provide clear error messages

5. **Special Handling**:
   - When updating attendees, replace entire list (API behavior)
   - When updating attachments, replace entire list (API behavior)
   - When updating times, both start and end should use same timezone
   - Preserve event organizer and creation metadata
