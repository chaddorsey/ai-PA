## Requirements

1. **Credential Loading**:
   - Load OAuth credentials from `~/.gmail-mcp/calendar.credentials.json`
   - Support `GMAIL_CREDENTIALS_PATH` environment variable override
   - Handle missing credentials gracefully

2. **OAuth Flow**:
   - Use `InstalledAppFlow` for user authentication
   - OAuth key file: `~/.gmail-mcp/gcp-oauth.calendar.desktop.json`
   - Support `GMAIL_OAUTH_PATH` environment variable override
   - Run local server for OAuth callback
   - Save credentials after successful authentication

3. **Token Refresh**:
   - Automatically refresh expired tokens using refresh token
   - Handle refresh failures gracefully
   - Save refreshed tokens to credential file

4. **Service Building**:
   - Build Calendar API service using `googleapiclient.discovery.build("calendar", "v3", credentials=creds)`
   - Return service object for use in tools

5. **Scopes**:
   - Use `https://www.googleapis.com/auth/calendar` scope (full read/write access)

6. **Error Handling**:
   - Clear error messages for missing credential files
   - Handle authentication failures with helpful instructions
   - Log authentication events appropriately
