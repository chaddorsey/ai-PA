# [25-10] Register tools with Letta

## Description
Register all calendar tools with Letta using the Letta SDK/API. Verify that JSON schemas are generated correctly from function signatures and docstrings, test tool discovery, and validate that parameter documentation is accessible to agents.

## Requirements

1. **Registration Script**: Create registration script (similar to `register_daily_briefing_tool.py`):
   - Use `client.tools.create_from_function(func=..., tags=[...])` for each tool
   - Register all 6 calendar tools:
     - `create_calendar_event`
     - `get_calendar_events`
     - `get_calendar_event`
     - `update_calendar_event`
     - `delete_calendar_event`
     - `list_calendars`
   - Attach all tools to specified agent

2. **Tool Functions**: 
   - Import tool functions from `letta.calendar_tools.tools`
   - Functions must follow Letta conventions (already verified in task 25-9)
   - Letta will extract function source automatically via `create_from_function`

3. **Schema Verification**:
   - Verify JSON schemas generated correctly from function signatures
   - Verify all parameters appear in schema
   - Verify parameter types are correct
   - Verify required vs optional parameters are marked correctly (based on `Optional[...] = None` pattern)
   - Verify descriptions from docstrings appear in schema

4. **Tool Metadata**:
   - Verify display names are appropriate (from function names)
   - Verify descriptions are clear (from docstrings)
   - Verify tags are appropriate (e.g., ["calendar", "crud", "custom"])

5. **Testing**:
   - Test tool registration succeeds for each tool
   - Test tools appear in Letta tool list
   - Test schema inspection shows correct structure
   - Test tool can be attached to agent

6. **Documentation**:
   - Document registration process
   - Document any configuration needed (OAuth credentials setup)
   - Document tool usage examples

## Implementation Plan

1. Create `letta/register_calendar_tools.py` following pattern from `register_daily_briefing_tool.py`:
   - Import tool functions from `letta.calendar_tools.tools`
   - Use `client.tools.create_from_function()` for each tool
   - Handle both dict and Pydantic model responses for tool creation

2. For each tool:
   - Import function: `from letta.calendar_tools.tools import create_calendar_event, ...`
   - Call `client.tools.create_from_function(func=tool_function, tags=["calendar", "crud", "custom"])`
   - Verify tool ID returned
   - Store tool IDs for attachment

3. Attach all tools to specified agent:
   - Use agent ID from environment variable or config
   - Attach all 6 tool IDs at once

4. Verify registration:
   - Check tool list in Letta
   - Inspect schemas for each tool (verify parameter extraction)
   - Verify docstring descriptions appear in tool metadata
   - Test that tools are accessible to agent

5. Create registration documentation:
   - Usage instructions
   - OAuth setup requirements
   - Tool usage examples
