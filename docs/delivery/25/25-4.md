# [25-4] Implement create event tool

## Description
Implement `create_calendar_event()` tool with comprehensive support for all event properties including summary (title), start/end times with timezone, description, location, attendees list, and Google Drive file attachments.

## Requirements

1. **Function**: `create_calendar_event()` with parameters:
   - `calendar_id` (str, required): Calendar ID (email) or "primary"
   - `summary` (str, required): Event title
   - `start_datetime` (str, required): ISO 8601 datetime string
   - `end_datetime` (str, required): ISO 8601 datetime string
   - `timezone` (str, optional): IANA timezone, default "America/New_York"
   - `description` (str, optional): Event description
   - `location` (str, optional): Event location text
   - `attendees` (List[str], optional): List of email addresses
   - `attachment_file_ids` (List[str], optional): List of Google Drive file IDs

2. **API Call**: Use `events.insert()` method
   - Build event body with all provided fields
   - Handle timezone specification correctly
   - Format attendees as list of `{"email": email}` objects
   - Format attachments as list of `{"fileId": file_id}` objects

3. **Response Format**:
   - Event object with full details including:
     - Event ID (for future updates/deletes)
     - Created/modified timestamps
     - Full event data
   - Status indicator (success/error)
   - Error message if failed

4. **Error Handling**:
   - Handle invalid calendar ID
   - Handle invalid datetime formats
   - Handle permission errors (calendar not shared, no write access)
   - Handle invalid Drive file IDs for attachments
   - Provide clear error messages

5. **Validation**:
   - Validate datetime format (ISO 8601)
   - Validate email addresses in attendees list
   - Validate end_datetime is after start_datetime
   - Validate calendar_id format
