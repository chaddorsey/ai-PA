## Requirements

1. **Test Authentication** (CoS #1):
   - Test credential loading works
   - Test OAuth flow on first run
   - Test token refresh
   - Test service building succeeds
   - Document authentication setup

2. **Test Create Event** (CoS #2):
   - Create event on primary calendar
   - Create event on shared calendar
   - Create event with all fields (summary, times, timezone, description, location, attendees, attachments)
   - Verify event appears in calendar
   - Verify attendees receive invitations
   - Verify attachments are linked

3. **Test Read Events** (CoS #3):
   - Retrieve events within date range
   - Retrieve single event by ID
   - Verify all event fields are returned correctly
   - Verify timezone information preserved

4. **Test Update Event** (CoS #4):
   - Update event summary
   - Update event times
   - Update event attendees
   - Update event description/location
   - Update event attachments
   - Verify partial updates work (other fields preserved)
   - Verify changes appear in calendar

5. **Test Delete Event** (CoS #5):
   - Delete event successfully
   - Test with different send_updates values
   - Verify event removed from calendar
   - Verify cancellation emails sent appropriately

6. **Test List Calendars** (CoS #6):
   - List all accessible calendars
   - Verify calendar IDs, names, permission levels returned
   - Verify primary calendar identified

7. **Test Timezone Handling** (CoS #7):
   - Create event with different timezones
   - Verify times stored correctly
   - Verify times retrieved correctly
   - Test with DST transitions if possible

8. **Test File Attachments** (CoS #8):
   - Attach Google Drive file to event
   - Verify attachment appears in event
   - Verify attachment accessible to attendees

9. **Test Error Handling** (CoS #9):
   - Test invalid calendar ID
   - Test invalid event ID
   - Test invalid datetime format
   - Test invalid email addresses
   - Test permission errors (calendar not shared)
   - Test authentication failures
   - Verify error messages are clear

10. **Test Tool Registration** (CoS #10):
    - Verify all tools registered
    - Verify schemas generated correctly
    - Verify tools accessible to agent

11. **Test Documentation** (CoS #11):
    - Verify docstrings complete
    - Verify parameter documentation accurate
    - Verify examples work

12. **Test End-to-End Workflow**:
    - Complete workflow: create → read → update → delete
    - Test with multiple calendars
    - Test with shared calendars
