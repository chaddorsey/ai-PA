# [25-3] Implement list calendars tool

## Description
Implement `list_calendars()` tool to retrieve all calendars accessible to the authenticated user, including calendar IDs (typically email addresses), display names (summary), access roles, and primary calendar indicator.

## Requirements

1. **Function**: `list_calendars() -> Dict[str, Any]`
   - No required parameters
   - Returns structured list of calendars

2. **API Call**: Use `calendarList.list()` method from Calendar API
   - Handle pagination if needed
   - Retrieve all accessible calendars

3. **Response Format**:
   - List of calendar objects with:
     - `id`: Calendar ID (email address or custom ID)
     - `summary`: Display name of calendar
     - `accessRole`: Permission level (owner, writer, reader, etc.)
     - `primary`: Boolean indicating if this is primary calendar
     - `timeZone`: Calendar timezone
   - Include total count
   - Status indicator (success/error)

4. **Error Handling**:
   - Handle API errors gracefully
   - Handle authentication failures
   - Return structured error response

5. **Documentation**: Comprehensive docstring explaining:
   - What the tool does
   - Return format
   - Example usage
