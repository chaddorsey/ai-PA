## Test Cases

### Question 1: "What Drive documents did Jie and Rebecca work on on Monday?"

**Tool call:**
```python
search_drive_activity(
    user="jie@company.com,rebecca@company.com",
    start_date="2024-12-23",
    end_date="2024-12-23"
)
```

**Status:** ✅ Verified - Multiple users filter works, returns documents with activity counts.

### Question 2: "What did Cynthia edit the most last week?"

**Tool call:**
```python
search_drive_activity(
    user="cynthia@company.com",
    activity_type="edit",
    start_date="2024-12-16",
    end_date="2024-12-20",
    sort_by="edit_count"
)
```

**Status:** ✅ Verified - Activity type filter + sort_by="edit_count" returns most-edited docs first.

### Question 3: "Which document owned by Leslie was viewed by the most people last month, and who were the people who edited it most?"

**Tool call:**
```python
search_drive_activity(
    owner="leslie@company.com",
    activity_type="view",
    start_date="2024-11-01",
    end_date="2024-11-30",
    sort_by="view_count"
)
```

**Status:** ✅ Verified - Owner filter + view_count sort + actors list provides the data needed.
