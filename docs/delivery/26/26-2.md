## Requirements

1. **Owner filtering**: Find documents owned by specific user(s)
   - Single email or comma-separated list
   - Uses Drive API `q='email' in owners` query

2. **Name search**: Search by document name
   - Partial match supported
   - Uses Drive API `name contains 'term'`

3. **File type filtering**: Filter by type
   - Options: "document", "spreadsheet", "presentation", "folder", "all"
   - Maps to MIME types

4. **Folder filtering**: Scope to specific folder
   - Uses Drive API `'folderId' in parents`

5. **Modification date filtering**: `modified_after` parameter
   - YYYY-MM-DD format

6. **Shared filtering**: Option to show only shared documents

## Implementation Plan

1. Create new function `get_drive_documents()` in `letta/drive_analytics_tools.py`
2. Build Drive API query from parameters
3. Execute paginated query
4. Return document list with metadata and links
