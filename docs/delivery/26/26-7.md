## Decision

After analysis, the existing tools serve a different purpose (memory-block workflow) and should NOT be deprecated:

- `get_drive_file_info` - Still useful for single file lookups
- `get_drive_mentions` - Memory-based mentions (different from activity search)
- `get_drive_analytics_summary` - Memory-based analytics (different from live search)
- `collect_daily_*` functions - Data collection for memory blocks

The new consolidated tools (`search_drive_activity`, `get_drive_documents`) provide complementary live-search capability.
