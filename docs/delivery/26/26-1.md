## Description

Create the unified `search_drive_activity` tool that replaces multiple existing tools with a single, powerful activity search interface. This tool supports filtering by user (actor), owner, date range, activity type, and folder.

## Requirements

1. **User filtering**: Filter by actor (who performed the action)
   - Single user or comma-separated list
   - Accept email or username
   - Uses Admin Reports API `userKey` parameter

2. **Owner filtering**: Filter by document owner
   - Single owner or comma-separated list
   - Requires post-filtering (API doesn't support directly)

3. **Date range**: Support `start_date` and `end_date` parameters
   - YYYY-MM-DD format
   - Uses Admin Reports API `startTime`/`endTime`

4. **Activity type filtering**: `edit`, `view`, `share`, `comment`, or `all`
   - Filters on event name from API response

5. **Folder filtering**: Optional folder ID to scope search

6. **Sorting**: `sort_by` parameter for `count`, `recent`, `name`

7. **Count limiting**: `count` parameter for max results

## Implementation Plan

1. Create new function `search_drive_activity()` in `letta/drive_analytics_tools.py`
2. Implement parameter parsing (comma-separated lists)
3. Build date range query
4. Query Admin Reports API with filters
5. Post-filter by owner if specified
6. Aggregate results by document
7. Sort and limit results
8. Return Dict[str, Any] (Letta compliance)
