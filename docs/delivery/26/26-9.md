## Root Cause Analysis

The current implementation has three bugs:

### Bug 1: Missing API Field
```python
# Current (line 225)
"fields": "nextPageToken, comments(id, content, author, createdTime, modifiedTime, resolved)"
```

The `mentionedEmailAddresses` field is not being requested from the Google Drive API.

### Bug 2: Incorrect Detection Logic
```python
# Current (line 799)
if MY_EMAIL.lower() in comment_content.lower():
```

This searches for the email string in the comment text, but Google Drive stores mentions in a dedicated `mentionedEmailAddresses` field, not necessarily in the visible text content.

### Bug 3: Missing Shared Drive Files
The file query used two separate queries for "owned" and "sharedWithMe" files, but this misses files in Shared Drives where the user has access through team/organizational permissions rather than explicit sharing.

## Implementation Plan

### 1. Update `_get_file_comments` function

Add `mentionedEmailAddresses` to the fields parameter:

```python
"fields": "nextPageToken, comments(id, content, author, createdTime, modifiedTime, resolved, mentionedEmailAddresses)"
```

### 2. Update `collect_daily_mentions` function

Replace string matching with array checking:

```python
# Get mentioned emails from the dedicated field
mentioned_emails = comment.get("mentionedEmailAddresses", [])

# Check if user's email is in the mentioned list
if any(MY_EMAIL.lower() == email.lower() for email in mentioned_emails):
    # ... process mention
```

### 3. Update file query to include Shared Drives

Replace two-query approach with single `corpora='allDrives'` query:

```python
params = {
    "q": all_files_query,
    "pageSize": 100,
    "fields": "nextPageToken, files(id, name, webViewLink)",
    "supportsAllDrives": True,
    "includeItemsFromAllDrives": True,
    "corpora": "allDrives",  # Include all Shared Drives you have access to
}
```
