## Requirements

1. **Tool Function**: `generate_daily_briefing()` with typed signature
2. **Input Parameters**:
   - `calendar_id` (str, optional): Calendar identifier (defaults to "cdorsey@concord.org")
   - `timezone` (str, optional): Timezone for time calculations (defaults to "America/New_York")
3. **Return Type**: Dictionary with:
   - `status`: "ok" | "error"
   - `briefing`: Markdown-formatted briefing string
   - `memory_content`: Content for memory block update
   - `timestamp`: ISO timestamp of when briefing was generated
   - `error_message`: Error message if status is "error"
4. **Docstring**: Comprehensive docstring explaining tool purpose, parameters, and return values
5. **Type Hints**: Full type annotations for all parameters and return value
