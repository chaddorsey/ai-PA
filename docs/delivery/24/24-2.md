## Requirements

1. **Import MCP Client**: Import `MCPCalendarClient` and `MCPError` from `scheduling_orchestrator.mcp_client`
2. **Configuration**: Read MCP server URL from environment variable `MCP_CALENDAR_SERVER_URL` with default fallback
3. **Client Initialization**: Create and configure MCP client instance in the tool function
4. **Error Handling**: Handle cases where MCP client is not available (ImportError)
5. **Environment Variables**: Support `MCP_CALENDAR_TIMEOUT` and `MCP_CALENDAR_RETRY_ATTEMPTS` configuration
