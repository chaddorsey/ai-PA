# [24-5] Implement available time calculation

## Description
Calculate available time blocks from the current moment to 5:00 PM Eastern. Merge adjacent available blocks, subtract elapsed minutes from the first partially elapsed block, and include any gap from the last busy item to 5:00 PM. Format time durations as "Xh, Y min" for totals and "X min" for individual blocks.

## Requirements

1. **Time Range**: Calculate from current time to 5:00 PM Eastern (17:00) only
2. **Block Identification**: Identify available time blocks between events
3. **Merge Adjacent Blocks**: Combine consecutive available time periods
4. **Elapsed Time**: Subtract elapsed minutes from first partially elapsed block
5. **End of Day Gap**: Include gap from last busy item to 5:00 PM if any
6. **Duration Formatting**: 
   - Total: "Xh, Y min" format (e.g., "3h, 15 min")
   - Individual blocks: "X min" format
   - First block uses "X min left", subsequent use "X min"
7. **Time Boundaries**: Only count time up to 5:00 PM, not beyond

## Implementation Plan

1. Define 5:00 PM cutoff time in Eastern timezone
2. Filter events to only those on today (not yesterday or tomorrow)
3. Filter events to only those that end after current time
4. Sort events by start time
5. Calculate available blocks:
   - Start from current time (or start of day if earlier)
   - For each event, check gap before it
   - After last event, check gap to 5:00 PM
6. Merge adjacent blocks
7. Calculate total available time
8. Format durations properly
9. Return list of available blocks with start/end times and durations
