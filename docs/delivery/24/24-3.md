## Requirements

1. **Date Range Calculation**: Calculate 3-day window (today-1 to today+1) in the specified timezone
2. **MCP Client Usage**: Use MCPCalendarClient.get_core_event_data() to fetch events
3. **Parameter Handling**: Remember that MCP Core_Event_Data has reversed parameter names:
   - "Before" = END date
   - "After" = START date
4. **Event Normalization**: Normalize event data from MCP format to internal format:
   - Extract start/end times from nested structure
   - Map "summary" to "title"
   - Extract attendees information
   - Handle all-day events (skip or mark appropriately)
5. **Error Handling**: Handle MCP errors gracefully and return appropriate error messages
6. **Async Handling**: Use asyncio to handle async MCP client calls
