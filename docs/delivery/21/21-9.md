## Requirements
- Register tool using Letta SDK (`create_tool` or `create_from_function`)
- Verify JSON schema renders correctly in Letta ADE
- Run manual test call with sample events
- Attach tool to agent
- Tool description and parameter docs are clear for LLM consumption

## Implementation Plan
1. Create registration script:
   - Follow pattern from `register_drive_analytics_tools.py` or `register_slack_analytics_tools.py`
   - Import `orchestrate_scheduling` function
   - Use Letta client to register tool
   - Add appropriate tags (e.g., "scheduling", "calendar", "custom")
2. Verify schema generation:
   - Check that Letta auto-generates correct JSON schema from function signature
   - Verify Pydantic models are properly serialized
   - Ensure docstring is used for tool description
   - Check parameter descriptions are clear
3. Test in Letta ADE:
   - Open Letta ADE and verify tool appears in tool list
   - Check schema shows correct input/output types
   - Verify descriptions are readable
4. Run manual test:
   - Prepare sample `events_by_participant` payload
   - Prepare sample `utterance` and `context_json`
   - Call tool via Letta SDK or ADE
   - Verify response structure matches schema
   - Check explanation is coherent
5. Attach to agent:
   - Use Letta SDK to attach tool to target agent
   - Verify agent can see and call the tool
   - Test agent invocation with natural language request

## Verification
- Tool visible and callable in Letta ADE
- Schema looks correct (types, descriptions, required fields)
- Manual test succeeds with sample data
- Tool attached to agent successfully
- Agent can invoke tool and receive valid responses
