## Requirements
- Use clingo Python API (`Control.ground/solve`); capture stats (on_model optional)
- Timeout guard; friendly errors; return status="unsat" with core/assumptions when useful
- Extract `start(Q, T)` and `occurs(Q, T)` predicates from optimal model
- Compute move deltas: which events need to move, by how much
- Calculate objective scores: moved minutes, focus block bonuses, preference penalties
- Collect ASP statistics: solve time, models found, optimization level reached

## Implementation Plan
1. Build clingo Control wrapper:
   - Initialize `Control` object
   - Load base ASP encoding (from task 21-3, 21-4)
   - Add facts programmatically (from normalizer output)
   - Ground the program
2. Implement solving with optimization:
   - Call `ctl.solve(on_model=on_model_handler)` with optimization mode
   - Set timeout (e.g., 30 seconds for typical horizons)
   - Capture the optimal model (first model when optimizing)
3. Extract model information:
   - Parse `start(Q, T)` predicates to get meeting start slot
   - Parse `occurs(Q, T)` predicates to get all occupied slots
   - Extract objective values from model cost vector
4. Compute move deltas:
   - Compare proposed schedule to original events
   - Identify events that need to move
   - Calculate shift amounts (in minutes)
   - Determine if moves are acceptable based on event protection level
5. Calculate objective scores:
   - Moved minutes: sum of all event shifts
   - Focus block bonus: count and length of created focus blocks
   - Preference penalty: sum of preference violations
6. Handle UNSAT cases:
   - Detect when no model exists
   - Extract unsatisfiable core if available
   - Return status="unsat" with blocking constraints identified
7. Collect statistics:
   - Solve time, number of models, optimization level
   - Store in debug.asp_stats for observability
