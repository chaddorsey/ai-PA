## Requirements
- Create test scenarios covering key use cases
- Define evaluation metrics for scheduling quality
- Implement test harness to run scenarios and collect metrics
- Validate that tool produces expected results for each scenario

## Implementation Plan
1. Define test scenarios:
   - **Common slot finding**: Simple case where all participants have free time
     - 3 participants, 1-hour meeting, next week
     - Expected: Finds common slot with minimal disruption
   - **Focus-block day reflow**: Optimize for creating long focus blocks
     - Executive with scattered 30-min meetings
     - Request: 1-hour meeting, prefer morning
     - Expected: Moves small meetings to create 2-3 hour focus block
   - **Recurring cadence with jitter**: Handle recurring meetings with small adjustments
     - Weekly team sync, but this week needs 15-min shift
     - Expected: Finds nearby slot, maintains cadence, minimal jitter
2. Define evaluation metrics:
   - **Total moved minutes**: Sum of all event shifts (lower is better)
   - **Longest focus block**: Maximum consecutive free time created (higher is better)
   - **Preference satisfaction %**: How well preferences were met (higher is better)
   - **Solve time**: Time to find solution (should be < target latency)
   - **Objective scores**: Breakdown of optimization objectives
3. Implement test harness:
   - Load scenario definitions (events, request, expected outcomes)
   - Run `orchestrate_scheduling` with scenario inputs
   - Extract metrics from response
   - Compare to expected outcomes (with tolerance for optimization variations)
   - Generate test report
4. Create scenario data:
   - JSON files or Python fixtures for each scenario
   - Include realistic calendar events (meetings, focus time, breaks)
   - Include context_json with policies and preferences
   - Include expected metric ranges (not exact values, due to optimization)

## Verification
- All three scenarios run successfully
- Metrics are calculated correctly
- Results match expected outcomes (within tolerance)
- Test harness produces clear reports
- Scenarios cover realistic use cases
