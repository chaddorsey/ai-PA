## Requirements
- Analyze unsatisfiable core from clingo to identify blocking constraints
- Convert technical constraints to human-readable explanations
- Generate ranked relaxation suggestions with expected impact
- Optionally use DSPy to generate natural language explanations
- Provide at least 3 actionable relaxations for over-constrained scenarios

## Implementation Plan
1. Extract unsatisfiable core:
   - Use clingo's UNSAT core extraction if available
   - Identify which constraints are blocking (busy slots, work hours, windows, min gaps)
   - Map constraints back to original events and preferences
2. Analyze blocking causes:
   - Categorize blockers: "all participants busy", "outside work hours", "window too narrow", "min gap too strict"
   - Identify specific time ranges or participants causing issues
   - Calculate how many constraints would need to relax to become satisfiable
3. Generate relaxation suggestions:
   - **Widen time window**: Suggest expanding the allowed time range
   - **Relax min gap**: Suggest reducing minimum gap between meetings
   - **Allow off-hours**: Suggest allowing meetings outside work hours (with warning)
   - **Remove participants**: Suggest optional participants if all required are busy
   - **Extend horizon**: Suggest looking further in the future
4. Rank relaxations by impact:
   - Estimate how much each relaxation improves feasibility
   - Prioritize relaxations that require minimal policy changes
   - Order by expected user acceptance (e.g., widen window before allow off-hours)
5. Generate human-readable explanations:
   - Use template-based explanations for common cases
   - Optionally use DSPy to generate more natural language
   - Include specific time ranges, participant names, and constraint values
6. Format relaxation suggestions:
   - Each suggestion includes: description, expected impact, policy change required
   - Provide concrete values (e.g., "relax min_gap from 15 to 10 minutes")

## Verification
- Over-constrained scenario yields ≥3 actionable relaxations ranked by expected impact
- Explanations are human-readable and actionable
- Relaxations correctly identify what needs to change
- Ranking prioritizes easier/more acceptable changes
- DSPy verbalization (if used) produces coherent explanations
