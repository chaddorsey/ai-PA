## Implementation Plan

### Phase 1: Schema Definition
1. **Create comprehensive Zod schema**:
   ```typescript
   const updateTaskSchema = z.object({
     taskId: z.string().describe("UUID of task to update"),
     name: z.string().optional().describe("New task name"),
     projectId: z.string().optional().describe("New project UUID to move task to"),
     tagIds: z.array(z.string()).optional().describe("New array of tag UUIDs (replaces existing)"),
     note: z.string().optional().describe("New task notes/description"),
     deferDate: z.string().optional().describe("New defer date (ISO string)"),
     dueDate: z.string().optional().describe("New due date (ISO string)"),
     flagged: z.boolean().optional().describe("New flagged status"),
     completed: z.boolean().optional().describe("New completion status")
   });
   ```
