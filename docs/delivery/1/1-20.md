## Requirements

### New Filter Parameters

#### **Time-Based Filters**
- `hasEstimate: boolean` - Tasks with/without time estimates
- `minEstimate: number` - Minimum estimated minutes
- `maxEstimate: number` - Maximum estimated minutes
- `isOverdue: boolean` - Tasks past their due date
- `isDueToday: boolean` - Tasks due today
- `isDueSoon: number` - Tasks due within N days
- `isDueThisWeek: boolean` - Tasks due within 7 days

#### **Content-Based Filters**
- `hasNotes: boolean` - Tasks with/without notes
- `minNoteLength: number` - Minimum note character count
- `hasDueDate: boolean` - Tasks with/without due dates
- `hasDeferDate: boolean` - Tasks with/without defer dates

#### **Status-Based Filters**
- `isAvailable: boolean` - Tasks that are available to work on now
- `isBlocked: boolean` - Tasks that are deferred (not yet available)
- `isStalled: boolean` - Tasks with no next actions
- `recentlyModified: number` - Tasks modified within N days

### Implementation Strategy

#### **Date Calculation Utilities**
```javascript
// Helper functions for date-based filtering
const isToday = (date) => {
  if (!date) return false;
  const today = new Date();
  return date.toDateString() === today.toDateString();
};

const isOverdue = (dueDate) => {
  if (!dueDate) return false;
  return dueDate < new Date();
};

const isDueSoon = (dueDate, days) => {
  if (!dueDate) return false;
  const soonDate = new Date();
  soonDate.setDate(soonDate.getDate() + days);
  return dueDate <= soonDate && dueDate >= new Date();
};
```

#### **Filter Application Logic**
Apply filters in logical order for performance:
1. **Cheap filters first**: boolean checks, basic comparisons
2. **Date calculations**: due date computations  
3. **Expensive filters last**: text length calculations, complex logic

### Step 1: Add Date Helper Functions
```javascript
// Add to omnifocus-mcp.omnijs after other helper functions
const isToday = (date) => {
  if (!date) return false;
  const today = new Date();
  return date.toDateString() === today.toDateString();
};

const isOverdue = (dueDate) => {
  if (!dueDate) return false;
  return dueDate < new Date();
};

const isDueSoon = (dueDate, days) => {
  if (!dueDate) return false;
  const soonDate = new Date();
  soonDate.setDate(soonDate.getDate() + days);
  return dueDate <= soonDate && dueDate >= new Date();
};

const isAvailableNow = (task) => {
  // Available if not completed, not dropped, and not deferred
  if (task.completed || !task.effectiveActive) return false;
  if (task.deferDate && task.deferDate > new Date()) return false;
  return true;
};
```

### Step 2: Enhance queryTasks Filter Logic
Add metadata filtering after existing filters but before exclusion logic:

```javascript
// Add metadata filters section in queryTasks
if (params.hasEstimate !== undefined) {
  tasks = tasks.filter(task => {
    const hasEst = task.estimatedMinutes && task.estimatedMinutes > 0;
    return hasEst === params.hasEstimate;
  });
}

if (params.minEstimate !== undefined) {
  tasks = tasks.filter(task => 
    task.estimatedMinutes && task.estimatedMinutes >= params.minEstimate
  );
}

if (params.maxEstimate !== undefined) {
  tasks = tasks.filter(task => 
    !task.estimatedMinutes || task.estimatedMinutes <= params.maxEstimate
  );
}

if (params.hasNotes !== undefined) {
  tasks = tasks.filter(task => {
    const hasNotes = task.note && task.note.trim().length > 0;
    return hasNotes === params.hasNotes;
  });
}

if (params.isOverdue !== undefined) {
  tasks = tasks.filter(task => isOverdue(task.dueDate) === params.isOverdue);
}

if (params.isDueToday !== undefined) {
  tasks = tasks.filter(task => isToday(task.dueDate) === params.isDueToday);
}

if (params.isDueSoon !== undefined) {
  tasks = tasks.filter(task => isDueSoon(task.dueDate, params.isDueSoon));
}

if (params.isAvailable !== undefined) {
  tasks = tasks.filter(task => isAvailableNow(task) === params.isAvailable);
}
```
