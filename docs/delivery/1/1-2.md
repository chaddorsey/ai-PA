## Requirements

### Functional Requirements
1. **Plugin Extension**: Add duration field support to `updateTask` method in `omnifocus-mcp.omnijs`
2. **Server Schema Update**: Add duration field to `updateTask` MCP tool schema with validation
3. **Duration Validation**: Validate duration values (positive numbers, reasonable ranges)
4. **Backward Compatibility**: Preserve existing `updateTask` functionality for all other fields

### Technical Requirements
1. **Field Integration**: Duration field integrates seamlessly with existing update logic
2. **Validation Rules**: Duration must be positive integer (minutes), maximum 1440 (24 hours)
3. **Optional Field**: Duration parameter is optional in update operations
4. **Preservation**: Existing duration preserved when not explicitly updated

## Implementation Plan

### Phase 1: Plugin Update
1. **Extend updateTask method** in `omnifocus-mcp.omnijs`:
   ```javascript
   lib.updateTask = params => {
     const t = flattenedTasks.find(x => bareId(x.id) === params.taskId);
     if (!t) throw new Error("Unknown task ID: " + params.taskId);

     // Existing field updates...
     if (params.estimatedMinutes !== undefined) {
       t.estimatedMinutesRemaining = params.estimatedMinutes;
     }
     
     return serializeTask(t);
   };
   ```

### Phase 2: Server Schema Update
1. **Update updateTask schema** in `server.ts`:
   ```typescript
   server.tool(

         .max(1440)
         .optional()

     },
     // ... existing implementation

   ```

### Phase 3: Integration Testing
1. **Test duration updates** through Claude conversations
2. **Verify validation** with invalid duration values
3. **Confirm preservation** of existing durations when not updated
