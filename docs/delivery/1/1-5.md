# 1-5 Implement listTasksByContext alias

[Back to task list](./tasks.md)

## Description

Implement `listTasksByContext` alias method in the OmniFocus plugin (`omnifocus-mcp.omnijs`) to provide OmniFocus 4 compatibility. This method serves as a direct alias to `listTasksByTag` since OmniFocus 4 renamed "contexts" to "tags", ensuring backward compatibility and intuitive usage for users familiar with either terminology.

This compatibility layer ensures that users can use either "context" or "tag" terminology naturally in their AI conversations, improving the user experience regardless of their OmniFocus version or preferred terminology.

## Requirements

### Functional Requirements
1. **Alias Implementation**: `listTasksByContext` that calls `listTasksByTag`
2. **Parameter Mapping**: Map context-related parameters to tag parameters
3. **Response Consistency**: Identical response format to `listTasksByTag`
4. **Parameter Validation**: Same validation as tag-based method
5. **Error Handling**: Consistent error messages regardless of alias used

### Non-Functional Requirements
1. **Zero Performance Overhead**: Alias should add no processing time
2. **API Consistency**: Maintain same behavior as primary method
3. **Documentation Clarity**: Clear documentation for both terminologies

### Technical Requirements
1. **Method Alias**: Simple method alias in plugin `lib` object
2. **Parameter Pass-through**: Direct parameter forwarding
3. **Code Maintainability**: Single source of truth for implementation

## Implementation Plan

### Phase 1: Alias Implementation
1. **Add alias method**:
   ```javascript
   lib.listTasksByContext = function(params) {
     return lib.listTasksByTag(params);
   };
   ```

3. **Integration testing**: Verify alias works through request router
