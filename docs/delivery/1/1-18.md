# 1-18 Implement universalQuery unified method

[Back to task list](./tasks.md)

## Description

Create a new `universalQuery` method that combines all search and filtering capabilities into a single, optimized API call. This method will unify the functionality of `searchTasks` and `queryTasks` while adding intelligent optimization for conversational AI workflows.

The universal query builder addresses the complexity of choosing between multiple query methods by providing a single entry point that can handle any combination of search, filtering, and exclusion operations with optimized performance.

## Implementation Plan

### Phase 1: Plugin Method Implementation
1. **Method signature** with comprehensive parameter support:
   ```javascript
   lib.universalQuery = params => {
     const startTime = Date.now();
     
     // Parameter extraction and validation
     const {
       // Search parameters
       search,
       fuzzy = true,
       
       // Filter parameters (from queryTasks)
       dueBefore, dueAfter, deferBefore, deferAfter,
       minDuration, maxDuration,
       flagged, completed, blocked, active,
       
       // Scope parameters
       projectId, tagId,
       
       // Exclusion parameters (from task 1-14)
       excludeProjectIds = [],
       excludeTagIds = [],
       excludeFolderIds = [],
       
       // Boolean tag logic (from task 1-16)
       requireAllTags = [],
       requireAnyTags = [],
       excludeAllTags = [],
       
       // Advanced status (from task 1-19)
       hasEstimate, hasNotes, isOverdue, isDueToday,
       
       // Result control
       maxResults = 100,
       includeCompleted = false
     } = params;
   };
   ```

2. **Intelligent execution strategy**:
   ```javascript
   // Determine optimal execution path
   let executionStrategy;
   if (search && search.trim()) {
     if (hasStructuredFilters(params)) {
       executionStrategy = 'searchWithFilters';
     } else {
       executionStrategy = 'searchOnly';
     }
   } else if (hasComplexFilters(params)) {
     executionStrategy = 'advancedFiltering';
   } else {
     executionStrategy = 'simpleQuery';
   }
   ```

3. **Unified filtering engine**:
   ```javascript
   function applyUniversalFilters(tasks, params) {
     return tasks.filter(task => {
       // Apply all filter types in optimized order
       return (
         passesStatusFilters(task, params) &&
         passesDateFilters(task, params) &&
         passesDurationFilters(task, params) &&
         passesExclusionFilters(task, params) &&
         passesBooleanTagLogic(task, params) &&
         passesAdvancedStatusFilters(task, params)
       );
     });
   }
   ```

### Phase 2: Search Integration
1. **Conditional search processing**:
   ```javascript
   if (search && search.trim()) {
     // Apply search scoring to filtered results
     const searchResults = applySearchScoring(filteredTasks, search, fuzzy);
     results = searchResults.map(item => ({
       ...item.task,
       searchScore: item.score,
       matchType: item.matchType
     }));
   } else {
     // Return filtered results without search scoring
     results = filteredTasks.map(serializeTask);
   }
   ```

2. **Hybrid result ranking**:
   ```javascript
   // Sort by search score if present, otherwise by relevance
   if (search) {
     results.sort((a, b) => {
       if (b.searchScore !== a.searchScore) {
         return b.searchScore - a.searchScore;
       }
       return a.name.localeCompare(b.name);
     });
   } else {
     // Sort by relevance (flagged, due date, creation date)
     results.sort(byRelevance);
   }
   ```

### Phase 3: Performance Optimization
1. **Smart caching strategy**:
   ```javascript
   // Generate optimal cache key based on parameter complexity
   const cacheKey = generateUniversalCacheKey(params);
   const cacheStrategy = determineCacheStrategy(params);
   ```

2. **Early termination optimization**:
   ```javascript
   // Stop processing when maxResults reached in search scenarios
   if (search && searchResults.length >= maxResults) {
     break; // Early termination for large datasets
   }
   ```
