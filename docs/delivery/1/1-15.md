## Implementation Plan

### Phase 1: Update queryTasks Schema
1. **Add exclusion parameters** to queryTasks tool registration:
   ```typescript
   server.tool(
     "queryTasks",
     "Query OmniFocus tasks with advanced multi-dimensional filtering including exclusions",
     {
       // ... existing parameters ...
       excludeProjectIds: z.array(z.string()).optional()
         .describe("Project UUIDs to exclude from results"),
       excludeTagIds: z.array(z.string()).optional()
         .describe("Tag UUIDs to exclude - tasks with any of these tags will be filtered out"),
       excludeFolderIds: z.array(z.string()).optional()
         .describe("Folder UUIDs to exclude - tasks in projects within these folders will be filtered out"),
     },
     async (args) => {
       const tasks = await callOmniFocus({ command: "queryTasks", args });
       return asJsonText(tasks);
     }
   );
   ```

### Phase 2: Update searchTasks Schema
