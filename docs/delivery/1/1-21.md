# [1-21] Fix searchTasks projectId filter bug

[Back to task list](./tasks.md)

## Description

Fix a critical bug in the `searchTasks` function where the `projectId` parameter filter is not working properly. The issue is in the conditional logic that checks `scope === 'all'` before checking for `params.projectId`, causing the function to always use all tasks instead of filtering to the specified project.

## Requirements

### Bug Description
- User query: `{ query: "Rick", projectId: "bdRrScFC2eT", active: true }`
- Expected: Only tasks from project `bdRrScFC2eT`
- Actual: Tasks from multiple projects (`ebyew1T9dkT`, `eYn5ihPRUit`, `kbK0sdUukSe`, etc.)

### Root Cause
The conditional logic in `searchTasks` (around line 1280) is:
```javascript
if (scope === 'all') {
  searchTasks = Array.from(flattenedTasks);  // Always runs first!
} else if (params.projectId) {
  // This block never executes because scope defaults to 'all'
}
```

Since `scope` defaults to `'all'`, the `params.projectId` check never runs.

### Solution
Reorder the conditional logic to check for specific parameters first:
1. Check `params.projectId` first
2. Check `params.tagId` second  
3. Check `scope` last as fallback

## Implementation Plan

### Step 1: Fix Conditional Logic Order
```javascript
// Current (broken):
if (scope === 'all') {
  searchTasks = Array.from(flattenedTasks);
} else if (params.projectId) {
  // Never reached
} else if (params.tagId) {
  // May not be reached
}

// Fixed:
if (params.projectId) {
  const project = flattenedProjects.find(p => bareId(p.id) === params.projectId);
  if (!project) {
    throw new Error(`Project not found with ID: ${params.projectId}`);
  }
  searchTasks = Array.from(project.flattenedTasks);
} else if (params.tagId) {
  const tag = flattenedTags.find(t => bareId(t.id) === params.tagId);
  if (!tag) {
    throw new Error(`Tag not found with ID: ${params.tagId}`);
  }
  searchTasks = Array.from(flattenedTasks).filter(task => 
    task.tags.some(taskTag => bareId(taskTag.id) === params.tagId)
  );
} else if (scope === 'all') {
  searchTasks = Array.from(flattenedTasks);
} else {
  searchTasks = Array.from(flattenedTasks);
}
```

### Step 2: Test the Fix
- Query with `projectId` should only return tasks from that project
- Query with `tagId` should only return tasks with that tag
- Query with `scope: 'all'` should return all tasks
- Default behavior (no specific filters) should return all tasks
