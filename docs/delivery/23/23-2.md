# [23-2] Upgrade Letta server to v0.14.0

## Requirements

### Functional Requirements
- Docker image updated from `letta/letta:latest` to `letta/letta:0.14.0`
- New image pulled successfully
- Service restarted and healthy
- Health endpoint returns version 0.14.0
- Service logs show no critical errors

### Technical Requirements
- Update `docker-compose.yml` with specific version tag
- Pull new Docker image
- Restart Letta service
- Verify health endpoint
- Check service logs for errors

## Implementation Plan

1. **Backup current configuration**
   - Create backup of `docker-compose.yml`
   - Note current image tag

2. **Update Docker Compose configuration**
   - Edit `docker-compose.yml`
   - Change `image: letta/letta:latest` to `image: letta/letta:0.14.0`
   - Save changes

3. **Pull new image**
   - Run `docker compose pull letta`
   - Verify image pulled successfully

4. **Restart service**
   - Run `docker compose up -d letta`
   - Wait for service to start

5. **Verify upgrade**
   - Check health endpoint: `curl http://localhost:8283/v1/health/ | jq .version`
   - Should return "0.14.0"
   - Check service logs: `docker compose logs letta`
   - Verify no critical errors

6. **Rollback preparation (if needed)**
   - Document rollback steps
   - Keep backup of docker-compose.yml
