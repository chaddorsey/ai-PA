## Implementation Details

### MCP Tool Schema
```json
{
  "name": "calendly_slots",
  "description": "Get all available Calendly slots (days & times)...",
  "inputSchema": {
    "type": "object",
    "properties": {
      "url": {"type": "string", "description": "..."},
      "timezone": {"type": "string", "default": "America/New_York"},
      "start": {"type": "string", "pattern": "^\\d{4}-\\d{2}-\\d{2}$"},
      "end": {"type": "string", "pattern": "^\\d{4}-\\d{2}-\\d{2}$"},
      "sniff_wait": {"type": "number", "default": 6.0},
      "per_day_delay": {"type": "number", "default": 0.35}
    },
    "required": ["url"]
  }
}
```

### JSON-RPC Request Example
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "calendly_slots",
    "arguments": {
      "url": "https://calendly.com/zarek-drozda",
      "timezone": "America/New_York",
      "start": "2025-10-15",
      "end": "2025-11-15"
    }
  }
}
```

### JSON-RPC Response Example
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"events\": [...]}"
      }
    ]
  }
}
```

## Notes

- The MCP protocol version is 2024-11-05
- Session ID management is required for Letta compatibility
- Tool results are wrapped in content array with text type
- Error codes follow JSON-RPC 2.0 specification:
  - -32602: Invalid params
  - -32603: Internal error
- Async/await used throughout for proper Playwright integration
