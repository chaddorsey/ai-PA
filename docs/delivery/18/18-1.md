## Notes

- The calendly_slots.py is a verified, production-ready implementation with the main entry point `slots_for_profile_or_event()` that handles both profile and event URLs
- Key function signature: `async def slots_for_profile_or_event(url: str, tz: str, start: str, end: str, sniff_wait: float, sleep: float) -> Dict[str, Any]`
- Returns structured JSON with events, days, times, UUIDs, and any errors
- Playwright requires running `playwright install chromium` after pip install, which will be handled in the Dockerfile (task 18-3)
- Version pins should be loose enough for flexibility but tight enough for reproducibility (e.g., `>=0.104.0` not `==0.104.0`)
