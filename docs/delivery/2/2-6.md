# 2-6 Implement Enhanced Project Navigation

[Back to task list](./tasks.md)

## Description

Implement enhanced project navigation capabilities in the OmniFocus plugin (`omnifocus-mcp.omnijs`) to enable AI assistants to understand and navigate complex project hierarchies and folder structures. This includes project hierarchy browsing, folder management, and project discovery features that make it easy for users to organize tasks within their project structure through natural conversation.

**Priority Rationale**: Project and folder navigation is used much more frequently than advanced perspective management, making this a higher-value feature for daily workflow optimization.

This functionality enables users to ask questions like "What projects are in my Work folder?", "Show me the hierarchy under my Client Projects", and "Where should I put this task related to the Johnson project?"

## Requirements

### Functional Requirements
1. **Project Hierarchy Access**: Navigate complete project folder structures with nested relationships
2. **Folder Management**: List folders, understand folder relationships, browse folder contents
3. **Project Discovery**: Find projects by folder, understand project organization patterns
4. **Hierarchical Context**: Provide context about where projects/folders sit in the overall structure
5. **Performance Optimization**: Efficient navigation of large project hierarchies without loading everything

### Non-Functional Requirements
1. **Response Time**: Hierarchy queries complete within 500ms for typical project structures
2. **Memory Efficiency**: Navigation doesn't load unnecessary project data
3. **Scalability**: Works efficiently with deep folder hierarchies (10+ levels)
4. **Consistency**: Hierarchical data matches current OmniFocus organization

### Technical Requirements
1. **API Integration**: Use OmniFocus folder and project hierarchy APIs effectively
2. **Caching Strategy**: Cache frequently accessed hierarchy data for performance
3. **Lazy Loading**: Load hierarchy data on-demand rather than all at once
4. **Existing Patterns**: Follow established serialization and error handling patterns

## Implementation Plan

### Phase 1: Folder Navigation Infrastructure
1. **Folder Access Methods**:
   ```typescript
   listFolders({ 
     parentFolderId?: string,    // List sub-folders of specific folder
     includeEmpty?: boolean,     // Include folders with no projects
     maxDepth?: number          // Limit hierarchy depth
   }): FolderInfo[]
   
   getFolderHierarchy({
     folderId?: string,         // Start from specific folder (root if null)
     includeProjects?: boolean, // Include projects in each folder
     maxDepth?: number         // Limit traversal depth
   }): FolderHierarchy
   ```

2. **Folder Data Structure**:
   ```typescript
   interface FolderInfo {
     id: string;
     name: string;
     parentFolderId?: string;
     projectCount: number;
     subfolderCount: number;
     path: string[];  // Full path from root
   }
   
   interface FolderHierarchy {
     folder: FolderInfo;
     subfolders: FolderHierarchy[];
     projects?: ProjectInfo[];
   }
   ```

### Phase 2: Enhanced Project Operations
1. **Project Navigation Methods**:
   ```typescript
   getProjectsByFolder({
     folderId: string,
     includeSubfolders?: boolean,  // Include projects from sub-folders
     includeCompleted?: boolean,   // Include completed projects
     sortBy?: 'name' | 'created' | 'modified'
   }): ProjectInfo[]
   
   getProjectPath({
     projectId: string
   }): ProjectPathInfo  // Full folder path to project
   ```

2. **Project Context Information**:
   ```typescript
   interface ProjectPathInfo {
     project: ProjectInfo;
     folderPath: FolderInfo[];    // Path from root to project's folder
     siblings: ProjectInfo[];     // Other projects in same folder
     parentFolder: FolderInfo;
   }
   ```

### Phase 3: Smart Project Discovery
1. **Project Search and Discovery**:
   ```typescript
   findProjectsByPath({
     folderPath: string[],        // Navigate by folder names
     projectName?: string,        // Find specific project
     fuzzyMatch?: boolean        // Allow partial name matching
   }): ProjectInfo[]
   
   getProjectSuggestions({
     taskKeywords?: string[],     // Suggest projects based on task content
     recentlyUsed?: boolean,      // Include recently accessed projects
     folderHint?: string         // Prefer projects in specific folders
   }): ProjectSuggestion[]
   ```

2. **Intelligent Organization**:
   - Analyze task content to suggest appropriate project placement
   - Track user patterns for smarter project recommendations
   - Understand folder naming conventions and organizational patterns
