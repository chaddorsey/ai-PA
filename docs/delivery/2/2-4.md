## Implementation Plan

### Completed Implementation
**server.ts Tool Registrations:**

1. **listInbox** (lines 89-102):
   ```typescript
   server.tool(
     "listInbox",
     "Return all tasks currently in the OmniFocus inbox for processing",
     {
       includeCompleted: z.boolean().optional(),
       limit: z.number().int().positive().optional()
     },
     async (args) => {
       const inboxItems = await callOmniFocus({
         command: "listInbox",
         args
       });
       return asJsonText(inboxItems);
     }
   );
   ```

2. **processInboxItem** (lines 105-130):
   ```typescript
   server.tool(
     "processInboxItem", 
     "Process an inbox item by performing multiple operations in a single call",
     {
       taskId: z.string(),
       projectId: z.string().optional(),
       tagIds: z.array(z.string()).optional(),
       name: z.string().optional(),
       note: z.string().optional(),
       flagged: z.boolean().optional(),
       deferDate: z.string().optional(),
       dueDate: z.string().optional(),
       estimatedMinutes: z.number().positive().max(1440).optional(),
       deleteTask: z.boolean().optional()
     },
     async (args) => {
       const result = await callOmniFocus({
         command: "processInboxItem",
         args
       });
       return asJsonText(result);
     }
   );
   ```
