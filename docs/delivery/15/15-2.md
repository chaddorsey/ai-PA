## Requirements
- Implement a shared `serializeProject` helper emitting `added`, `modified`, status flags, folder context, completion status, and task IDs.
- Support optional expansion for task name hydration, folder path details, and completion filtering metadata needed for `full` responses.
- Ensure existing timestamp utilities (`serializeTimestamped`) are reused.
- Maintain compatibility with current cache invalidation and command semantics.

## Implementation Plan
- Add the new serializer near existing task serializers in `extra-files/omnifocus-mcp.omnijs`.
- Update `lib.listProjects` (and related helpers) to use the serializer, accepting flags for included fields and completion-state filtering.
- Verify bridge commands (`getProjectById`, `listProjects`, `listProjectsByFolder` if applicable) can leverage the richer serializer.
- Handle error cases gracefully when folders or tasks are missing.

## Verification
- Manual `osascript` / MCP calls confirm populated timestamps and folder metadata.
- Unit or smoke scripts demonstrate presence of new fields without breaking existing clients.
