# 22-6 Merge event details with utterance constraints

[Back to task list](./tasks.md)

## Description
Combine extracted event details with additional constraints/preferences from utterance to construct complete SchedulingProblem. Handle conflicts and overrides. Set default search timeframe to next 28 days (current and future) if not specified. Ensure only one meeting per request is supported.

## Requirements
- Create function `merge_event_details_with_utterance` that takes:
  - `extracted_event_details`: Dict from event_extractor (participants, duration, title, location, etc.)
  - `scheduling_problem`: SchedulingProblem extracted from utterance
  - `context_json`: Context for timeframe defaults
- Merge logic:
  - Participants: Use event participants as base, but utterance may add/remove participants
  - Duration: Use event duration as base, utterance can override
  - Title: Use event title as base, utterance can override
  - Location: Use event location as base, utterance can override
  - Time constraints: Merge utterance time_window/preferred_times with event's current time
  - Preferences: Merge utterance preferences with any event-based preferences
- Handle conflicts: Utterance preferences override event defaults
- Set default timeframe: If not specified in context, default to next 28 days (current and future)
- Validate: Ensure only one meeting per request (already enforced by single event_id)
- Return: Updated SchedulingProblem ready for scheduling

## Implementation Plan
1. Create function `merge_event_details_with_utterance` in event_extractor.py or new module
2. Implement merge logic for each field:
   - Participants: Start with event participants, merge with utterance participants
   - Duration: Use event duration unless utterance specifies different
   - Title: Use event title unless utterance specifies different
   - Location: Use event location unless utterance specifies different
   - Time constraints: Merge utterance constraints with event's current time as reference
3. Handle timeframe: Set default to 28 days if not in context
4. Integrate into orchestrate_scheduling.py after event extraction
5. Update SchedulingProblem with merged values
