## Requirements
- When rescheduling, add the original event to events_by_participant before normalization
- Ensure original event has correct flags:
  - `flexible: True` (can be moved)
  - `internal_only: True` (must be internal-only to be moved)
  - `protected: False` (can be overridden if needed)
  - `locked: False` (can be moved)
- Event should be added to each participant's calendar in events_by_participant
- Normalizer should handle the event like any other calendar event
- Event should appear in busy_slots and event_metadata after normalization
- This allows the solver to consider moving/overriding the original event

## Implementation Plan
1. After event extraction, add original event to events_by_participant

3. Add event to each participant's event list

5. Verify event appears in normalized data
