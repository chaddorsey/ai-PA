# 22-5 Extract event details for scheduling problem

[Back to task list](./tasks.md)

## Description
Create function to extract participants, duration, title, location, and other metadata from identified event. Validate event is internal-only if moving is required. This function takes the fetched event (from event_id or natural language identification) and extracts all necessary details to construct a SchedulingProblem for rescheduling.

## Requirements
- Create function `extract_event_details_for_rescheduling` that takes:
  - `event`: Event dictionary from MCP (with summary, id, start, end, attendees_list, etc.)
  - `event_owner_id`: The participant ID whose calendar the event was found in
- Extract and return:
  - Participants: List of all participants (from attendees_list, or owner if solo)
  - Duration: Calculated from start and end times
  - Title: From summary field
  - Location: From location field if available
  - Current start/end times: For reference
  - Event ID: For tracking
- Validate that event is internal-only (if moving is required)
- Handle edge cases:
  - Solo events (no attendees)
  - Events with missing fields
  - All-day events (should be skipped or handled specially)
- Return structured data that can be used to construct SchedulingProblem

## Implementation Plan
1. Create function `extract_event_details_for_rescheduling` in a new module or add to existing module
2. Extract participants from attendees_list, fallback to owner if empty
3. Calculate duration from start/end times
4. Extract title, location, and other metadata
5. Validate internal_only flag
6. Return structured dict with all extracted details
7. Integrate into orchestrate_scheduling.py when fetched_event_by_id is available
8. Use extracted details to construct/update SchedulingProblem

## Verification
- Function correctly extracts all event details
- Participants list includes all attendees plus owner
- Duration is calculated correctly from start/end times
- Validation catches external events that cannot be moved
- Handles edge cases gracefully (missing fields, solo events, etc.)
