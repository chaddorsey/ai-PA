## Requirements
- Add `original_event_id` field to Proposal schema (optional, only present for rescheduling)
- Add `original_event_details` field to Proposal schema (optional, contains original event metadata)
- Populate these fields when creating proposals for rescheduling operations
- Store original event ID and key details (title, start, end, participants, location)
- Ensure fields are only populated when `is_rescheduling` is true
- Make original event information easily accessible to agent and users
