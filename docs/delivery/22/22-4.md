# 22-4 Implement event identification from natural language

[Back to task list](./tasks.md)

## Description
Build function to match extracted event identifiers against fetched calendar events. Handle fuzzy matching for participant names, date/time ranges, and titles. For recurring events, identify only the specific instance mentioned in the request.

## Requirements
- Create function `identify_event_from_natural_language` that takes:
  - `event_identifiers`: Dict with participant_names, dates, times, titles
  - `events_by_participant`: Dict mapping participant IDs to their calendar events
  - `context_json`: Context with participant information for name-to-email mapping
- Implement fuzzy matching for:
  - Participant names: Match names to email addresses from context, then find events with those participants
  - Dates: Parse date references (e.g., "Dec. 10th", "Monday", "tomorrow") and match against event dates
  - Times: Parse time references (e.g., "2pm", "morning", "afternoon") and match against event times
  - Titles: Fuzzy string matching on event titles (e.g., "check-in" matches "Weekly Check-in")
- Score matches based on how many identifiers match
- Return the best matching event (or None if no good match)
- For recurring events, only match the specific instance mentioned (by date/time)
- Handle edge cases: multiple matches, no matches, ambiguous matches

## Implementation Plan
1. Create new module `event_matcher.py` in `letta/scheduling_orchestrator/`
2. Implement `identify_event_from_natural_language` function:
   - Map participant names to email addresses using context
   - Parse date references to actual dates
   - Parse time references to time ranges
   - Score each event based on matching criteria
   - Return best match or None
3. Implement helper functions:
   - `parse_date_reference`: Convert "Dec. 10th", "Monday", etc. to actual dates
   - `parse_time_reference`: Convert "2pm", "morning", etc. to time ranges
   - `fuzzy_match_title`: Fuzzy string matching for event titles
   - `score_event_match`: Calculate match score based on all identifiers
4. Integrate into `orchestrate_scheduling.py` when `is_rescheduling` is true and `event_id` is not provided
5. Handle errors gracefully (no match found, ambiguous matches)
