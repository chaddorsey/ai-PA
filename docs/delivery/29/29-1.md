## Description

Create the game-state-service, a Python service that polls the ESPN API for real-time game data, maintains game state, detects changes, and emits events to the insight-engine.

## Requirements

1. **ESPN API Integration**
   - Poll scoreboard endpoint to find active games
   - Poll summary endpoint for active game details
   - Handle API errors gracefully with retry logic
   - Respect implicit rate limits (no faster than 2-sec intervals)

2. **Game State Model**
   - Maintain comprehensive GameState dataclass
   - Track: quarter, clock, down, distance, possession, scores
   - Track: recent plays (last 20), current drive, win probability
   - Parse play-by-play from drives data

3. **Change Detection**
   - Detect new plays
   - Detect score changes
   - Detect turnovers
   - Detect possession changes
   - Detect clock state changes (running, stopped, 2-min warning)
   - Detect quarter/period changes

4. **Adaptive Polling**
   - Fast polling (2-3 sec) during active play
   - Medium polling (5 sec) during stoppages
   - Slow polling (30 sec) during halftime
   - Pre-game polling (60 sec) before kickoff

5. **Event Emission**
   - HTTP POST to insight-engine on state changes
   - Include change type and full game state
   - Queue events if insight-engine unavailable

6. **REST API Endpoints**
   - `GET /health` - Health check
   - `GET /state` - Current game state
   - `POST /start` - Start tracking a game (game_id or team name)
   - `POST /stop` - Stop tracking
   - `GET /games` - List current NFL games

### Polling Loop Logic

```python
async def poll_loop(self):
    while self.active:
        try:
            raw_data = await self.espn.get_game_summary(self.game_id)
            new_state = self.parse_game_state(raw_data)
            changes = self.detect_changes(self.state, new_state)
            
            for change in changes:
                await self.emitter.emit(change['type'], {
                    'change': change,
                    'state': new_state
                })
            
            self.state = new_state
            interval = self.calculate_poll_interval()
            await asyncio.sleep(interval)
        except Exception as e:
            logger.error(f"Poll error: {e}")
            await asyncio.sleep(5.0)
```
