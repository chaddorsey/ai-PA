## Requirements

1. **Event Reception**
   - HTTP endpoint to receive game state change events
   - WebSocket connection from companion-ui for insight delivery
   - Queue events for processing

2. **Insight Generation**
   - Fast path: Template-based insights for common situations
   - LLM path: Generate nuanced insights for significant events
   - Model-agnostic LLM integration (support Claude, GPT, etc.)
   - Rate-limit LLM calls to avoid API limits

3. **Insight Classification**
   - Classify events by significance (1-10 scale)
   - Determine insight type (explanation, prediction, etc.)
   - Assess time-sensitivity (immediate vs. can wait)

4. **Delivery Management**
   - Maximum 4 insights per minute
   - Minimum 8-second gap between deliveries
   - Priority queue for insights
   - Immediate delivery for high-priority events
   - Queue lower-priority during intense action

5. **User Attention Model**
   - Track game pace and intensity
   - Adapt frequency to game state
   - Respect user engagement signals

6. **Letta Integration**
   - Route user questions to main agent
   - Include game context in agent calls
   - Handle agent responses asynchronously

7. **REST/WebSocket API**
   - `POST /event` - Receive game state events
   - `GET /health` - Health check
   - `WS /ws` - WebSocket for companion-ui connection
   - `POST /query` - Handle user questions

# insight_generator.py
class InsightGenerator:
    def __init__(self, templates: Dict, llm_client: LLMClient):
        pass
    
    async def generate_insights(self, event: Dict, state: GameState) -> List[Insight]:
        # Fast path for common situations
        template_insights = self.generate_template_insights(event, state)
        
        # LLM path for significant events
        if self.needs_llm_insight(event, state):
            llm_insight = await self.generate_llm_insight(event, state)
            if llm_insight:
                template_insights.append(llm_insight)
        
        return template_insights

# delivery_manager.py
class DeliveryManager:
    MAX_INSIGHTS_PER_MINUTE = 4
    MIN_GAP_SECONDS = 8.0
    
    def __init__(self):
        self.queue = asyncio.PriorityQueue()
        self.last_delivery_time = 0
        self.recent_deliveries = []
    
    async def queue_insight(self, insight: Insight):
        priority = -insight.priority  # Higher priority = lower queue number
        await self.queue.put((priority, insight))
    
    async def delivery_loop(self, send_callback):
        while True:
            insight = await self.get_next_deliverable()
            if insight:
                await send_callback(insight)
                self.last_delivery_time = time.time()
                self.recent_deliveries.append(time.time())
            await asyncio.sleep(0.5)
    
    def can_deliver_now(self) -> bool:
        now = time.time()
        # Check minimum gap
        if now - self.last_delivery_time < self.MIN_GAP_SECONDS:
            return False
        # Check rate limit
        recent = [t for t in self.recent_deliveries if now - t < 60]
        return len(recent) < self.MAX_INSIGHTS_PER_MINUTE

# llm_client.py
class LLMClient:
    def __init__(self, provider: str = "anthropic"):
        self.provider = provider
        self.rate_limiter = RateLimiter(calls_per_minute=10)
    
    async def generate_insight(self, prompt: str) -> Optional[str]:
        if not self.rate_limiter.can_call():
            return None
        
        if self.provider == "anthropic":
            return await self._call_anthropic(prompt)
        elif self.provider == "openai":
            return await self._call_openai(prompt)

### Insight Data Model

class Insight:
    id: str

    priority: int  # 1-10, higher = more important
    timing: str  # immediate, post_play, stoppage

    body: str  # Full explanation
