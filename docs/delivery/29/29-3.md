## Requirements

1. **Web Interface**
   - Single-page application served by Flask
   - Dark theme optimized for second-screen viewing
   - Minimal, distraction-free design
   - Responsive for tablet/phone use

2. **Session Management**
   - Start session with team/game selection
   - Display current game status header
   - End session button
   - Auto-reconnect on connection loss

3. **Insight Display**
   - Real-time insight cards via WebSocket
   - Differentiate insight types visually
   - Show timestamp for each insight
   - Scrollable history of insights
   - New insights highlighted briefly

4. **User Input**
   - Text input for questions
   - Send questions to insight-engine
   - Display responses in chat format
   - Loading indicator during response generation

5. **Game Status Display**
   - Current score
   - Quarter and clock
   - Down and distance
   - Possession indicator
   - Updates in real-time

6. **WebSocket Connection**
   - Connect to insight-engine WebSocket
   - Receive pushed insights
   - Send user queries
   - Handle reconnection gracefully

```javascript
// companion.js
class CompanionClient {
    constructor() {
        this.ws = null;
        this.gameState = null;
        this.insights = [];
    }
    
    connect() {
        this.ws = new WebSocket(`ws://${location.host}/ws`);
        this.ws.onmessage = (event) => this.handleMessage(JSON.parse(event.data));
        this.ws.onclose = () => this.reconnect();
    }
    
    handleMessage(msg) {
        switch(msg.type) {
            case 'insight':
                this.displayInsight(msg.data);
                break;
            case 'game_state':
                this.updateGameState(msg.data);
                break;
            case 'response':
                this.displayResponse(msg.data);
                break;
        }
    }
    
    sendQuery(text) {
        this.ws.send(JSON.stringify({type: 'query', text: text}));
        this.displayUserMessage(text);
    }
    
    startSession(teamOrGame) {
        this.ws.send(JSON.stringify({type: 'start', query: teamOrGame}));
    }
}
```

```python
# app.py
from flask import Flask, render_template
from flask_sock import Sock

app = Flask(__name__)
sock = Sock(app)

@app.route('/')
def index():
    return render_template('index.html')

@sock.route('/ws')
def websocket(ws):
    # Connect to insight-engine
    engine_ws = connect_to_engine()
    
    # Bidirectional message relay
    async def relay_from_engine():
        async for msg in engine_ws:
            ws.send(msg)
    
    async def relay_to_engine():
        while True:
            msg = ws.receive()
            await engine_ws.send(msg)
    
    # Run both relays
    asyncio.gather(relay_from_engine(), relay_to_engine())
```
