### E2E Test Scenarios

1. **Add and track new series:**
   - Add "The Mandalorian" to tracked series
   - Verify JustWatch lookup succeeded
   - Verify entry created with correct metadata

2. **Manual progress override:**
   - Add series with existing watch history elsewhere
   - Mark "seasons 1-3" as watched
   - Sync from streaming service
   - Verify only S4+ shown as unwatched

3. **Status lifecycle:**
   - Add series → watching
   - Complete all episodes → finished
   - New season appears → back to in_progress

4. **Multi-service availability:**
   - Add series available on multiple services
   - Change preferred service
   - Verify sync uses correct service

5. **Watchlist integration:**
   - Add item to watchlist
   - Run reconcile_watchlist_tracking
   - Verify auto-tracked entry created
