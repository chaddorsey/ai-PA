# [28-2] Add/remove tracked series tools

[Back to task list](./tasks.md)

## Description

Implement `add_tracked_series` and `remove_tracked_series` Letta tools for managing the tracked series list. The add tool should perform JustWatch lookup to find series metadata automatically.

## Requirements

### add_tracked_series(title, preferred_service, username)

1. Search JustWatch for the title
2. Get series metadata (ID, available services, season counts)
3. If multiple matches, return top candidates for confirmation
4. Create `tracked_series` entry with:
   - `tracking_status = 'watching'`
   - `watch_status = 'not_started'`
   - `preferred_service` = specified or first available
   - `available_services` = JSON from JustWatch
5. Optionally trigger initial sync_series_progress
6. Return success with series details

### remove_tracked_series(title, username)

1. Find matching tracked_series entry
2. Delete from tracked_series table
3. Optionally: Keep or delete associated series_progress data
4. Return confirmation

## Implementation Plan

1. Create `add_tracked_series` function in sports_media_tools.py
2. Integrate with existing JustWatch scraper for lookups
3. Create `remove_tracked_series` function
4. Add corresponding API endpoints in content_api.py if needed
5. Handle partial title matches gracefully
