## Description

Create the `tracked_series` table in the content database and extend the existing `series_progress` table with fields for manual progress tracking.

## Requirements

1. Create `tracked_series` table with:
   - Core identity fields (id, user_id, title, justwatch_id, imdb_id)
   - Status fields (tracking_status, watch_status)
   - Service fields (preferred_service, available_services JSON)
   - Progress fields (total_seasons_known, total_episodes_known, watched_episode_count)
   - Manual override field (manual_progress JSON)
   - Timestamps (last_synced_at, last_availability_check, added_at, updated_at)
   - Metadata (notes, auto_tracked_from_watchlist)
   - Unique constraint on (user_id, justwatch_id)

2. Add indexes for common queries:
   - (user_id, tracking_status)
   - (user_id, preferred_service)

3. Extend `series_progress` table:
   - Add `is_manual` BOOLEAN DEFAULT FALSE
   - Add `source` TEXT DEFAULT 'scraped'

4. Add API endpoints in content_api.py for CRUD operations

## Implementation Plan

1. Add schema creation to `content_api.py` init_db function
2. Create helper functions for tracked_series CRUD
3. Add REST endpoints:
   - POST /tracked-series (create)
   - GET /tracked-series (list with filters)
   - GET /tracked-series/{id} (get one)
   - PUT /tracked-series/{id} (update)
   - DELETE /tracked-series/{id} (delete)
4. Extend series_progress table if columns don't exist
