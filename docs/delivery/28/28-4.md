## Requirements

### mark_episodes_watched(title, watched_spec, note, username)

1. Parse flexible `watched_spec` formats:
   - `"seasons 1-3"` → Mark seasons 1, 2, 3 as fully watched
   - `"through S2E5"` or `"up to S2E5"` → Mark everything through S2E5
   - `"S1E3"` → Mark single episode
   - `"S3E1-5"` → Mark range within season
   - `"last episode S1E8"` → Same as "through S1E8"

2. Store in `manual_progress` JSON field:
   ```json
   {
     "watched_through": {"season": 2, "episode": 5},
     "additional_watched": [{"season": 3, "episode": 1}],
     "source_note": "Originally watched on Amazon Prime"
   }
   ```

3. Update `watch_status` based on manual + scraped progress
4. Return confirmation with summary of marked episodes

### clear_manual_progress(title, username)

1. Find matching tracked_series entry
2. Clear manual_progress field
3. Recalculate watch_status from scraped data only
4. Return confirmation

### Progress calculation logic

When calculating unwatched episodes:
1. Start with streaming service's reported progress (series_progress table)
2. Union with manual_progress entries
3. Report only truly unwatched episodes
