## Requirements

### update_tracking_status(title, status, username)

1. Find matching tracked_series entry
2. Validate status is one of: 'watching', 'finished', 'dropped', 'on_hold'
3. Update tracking_status field
4. Update updated_at timestamp
5. Return confirmation with new status

Status meanings:
- `watching`: Actively monitoring, sync regularly
- `finished`: Completed current seasons, monitor for new seasons less frequently
- `dropped`: Stopped watching intentionally, don't sync
- `on_hold`: Paused watching, keep tracking but lower priority

### set_preferred_service(title, service, username)

1. Find matching tracked_series entry
2. Validate service exists in available_services
3. Update preferred_service field
4. Return confirmation
