## Requirements

### sync_all_active_series(username)

1. Get all tracked_series where tracking_status = 'watching'
2. For each, call existing sync_series_progress
3. Update last_synced_at timestamp
4. Return summary: series synced, episodes updated, errors

### check_new_seasons(username)

1. Get tracked_series where tracking_status IN ('watching', 'finished')
2. For each, query JustWatch for current season count
3. Compare to total_seasons_known
4. If new season detected:
   - Update total_seasons_known
   - Set watch_status = 'in_progress'
   - Log detection for memory block
5. Return: list of series with new seasons

Frequency: Weekly (configured in scheduler)

### refresh_service_availability(username)

1. Get all tracked_series
2. For each, query JustWatch for current availability
3. Update available_services JSON
4. Detect:
   - New services with the content
   - Removed services (seasons no longer available)
5. Update last_availability_check timestamp
6. Return summary of changes

### reconcile_watchlist_tracking(username)

1. Get all watchlist items from content database
2. For each watchlist series:
   - Check if already in tracked_series
   - If not, create entry with auto_tracked_from_watchlist=TRUE
3. Return: count of newly tracked series

## Implementation Plan
