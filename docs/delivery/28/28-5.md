## Requirements

### get_tracked_series(status_filter, service_filter, username)

1. Query tracked_series table with optional filters:
   - `status_filter`: 'watching', 'finished', 'dropped', 'on_hold', 'all'
   - `service_filter`: 'hulu', 'netflix', 'disney', etc. or 'all'
2. Return list with:
   - title, tracking_status, watch_status
   - preferred_service
   - episode progress (watched/total)
   - next_episode if in_progress
3. Sort by tracking_status priority, then title

### get_series_status(title, username)

1. Find matching tracked_series entry
2. Return comprehensive status:
   - All tracking/watch status fields
   - Available services with season counts
   - Episode-level progress (from series_progress)
   - Manual progress overrides
   - Next unwatched episode
   - Last sync timestamp

### check_series_availability(title)

1. Query JustWatch for current availability
2. Return:
   - All streaming services with the series
   - Season count per service
   - Deep link URLs if available
3. Does NOT require series to be tracked
