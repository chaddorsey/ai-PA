## Requirements

### Tool Consolidation
- Simplify from 7+ tools to 5 focused tools
- `schedule_reminder`: Agent messages (with optional category instead of priority)
- `schedule_action`: Combined script + HTTP scheduling (explicit action_type)
- `schedule_advanced`: Multi-action workflows with full control
- `list_scheduled_jobs`: Structured filtering with Eastern Time display
- `manage_scheduled_job`: Single tool for update/pause/resume/cancel

### Natural Language Scheduling
- Parse human-friendly time expressions: "in 30 minutes", "tomorrow at 9am", "every day at 8am"
- Default to Eastern Time (America/New_York) for all schedules
- Store as UTC in backend, display as ET by default
- Support `show_utc=true` flag for UTC display
- Handle recurring patterns: "every Monday at 5pm", "every 2 hours"

### Agent Identity Management
- Auto-populate `created_by` from MCP session context
- Extract agent ID from custom HTTP header (`X-Agent-ID`)
- Fallback to URL query parameter (`?agent_id=...`)
- Support "me"/"self" aliases in filters that resolve to current agent
- Default `agent_id` to requesting agent for reminders

### Error Messages
- Provide exhaustive, instructive error messages
- Include specific description of what was wrong
- Show correct examples tailored to the failed request
- Guide users on parameter combinations (e.g., script args vs HTTP body)
- Explain timezone formats, schedule expressions, etc.

### Schema Changes
- Remove `priority` field from reminders (YAGNI)
- Add `category` field for organizational grouping
- Explicit `action_type` discriminator in `schedule_action`
- Structured filter objects in `list_scheduled_jobs`
- `operation` parameter in `manage_scheduled_job` (update/pause/resume/cancel)

## Implementation Summary

### Completed Components

#### 1. MCP Tool Schemas (`scheduler-mcp/src/scheduler_mcp/tools_v2.py`)
- `ScheduleReminderParams`: Agent messages with category support
- `ScheduleActionParams`: Combined script/HTTP with explicit action_type
- `ScheduleAdvancedParams`: Full control for complex workflows
- `ListScheduledJobsParams`: Structured filtering with JobFilters
- `ManageScheduledJobParams`: Single tool for update/pause/resume/cancel

#### 2. Updated MCP Server (`scheduler-mcp/src/scheduler_mcp/server_v2.py`)
- Agent identity extraction via `AgentIdentityMiddleware`
- Context variable `current_agent_id` for tracking sessions
- Extracts from `X-Agent-ID` header or `agent_id` query param
- Auto-populates `created_by` in all tool calls
- Resolves "me"/"self" aliases in filters
- Comprehensive error handling with custom exceptions

#### 3. Error Message System (`scheduler-mcp/src/scheduler_mcp/errors.py`)
- `SchedulerToolError` base exception with `to_dict()` method
- Context-aware error generators:
  - `missing_required_parameter_error`
  - `invalid_parameter_combination_error`
  - `invalid_schedule_expression_error`
  - `invalid_timezone_error`
  - `script_not_allowlisted_error`
  - `invalid_operation_for_parameter_error`
  - `job_not_found_error`
- Each error includes specific examples tailored to the failed request

#### 4. Natural Language Schedule Parser (`scheduler-service/src/scheduler_service/services/schedule_parser.py`)
- Parses human-friendly time expressions
- Supports patterns:
  - Relative: "in 30 minutes", "in 2 hours"
  - Absolute: "tomorrow at 9am", "next Monday at 5pm"
  - Recurring daily: "every day at 8am"
  - Recurring weekly: "every Monday at 5pm", "every weekday at 9am"
  - Intervals: "every 15 minutes", "every 2 hours"
- Eastern Time defaults with UTC storage
- Timezone validation
- Display formatting (ET/UTC toggle)

#### 5. Category Field Support
- Database migration: `002_add_category_field.py`
- Added `category` column to `jobs` table (nullable String(128))
- Index on category for filtering
- Updated ORM model in `models/job.py`
- Updated Pydantic schemas in `schemas/jobs.py`
- Updated REST API routes in `routes/jobs.py`
- Category included in job creation, updates, and responses

#### 6. Dependencies Added
- `scheduler-service/pyproject.toml`: Added `dateparser` and `python-dateutil`
