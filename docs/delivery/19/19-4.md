## Requirements
- Define action types (HTTP request, webhook, script execution) with configuration metadata stored in Postgres.
- Implement secure execution pipeline with allow-listed scripts and environment controls.
- Capture responses/results, associate with execution records, and store textual summaries for embeddings.
- Provide mechanisms to trigger downstream processing (e.g., message queue, Letta notification, database ingestion hooks).
- Update documentation with examples (news download, web scraping, external task import).

## Implementation Plan
1. Design action configuration schema (tables/models) derived from Task 19-1 plan.
2. Implement HTTP/webhook executor using `httpx` with timeout/retry policies.
3. Implement script executor calling allow-listed commands via subprocess with logging and safety checks.
4. Store execution outcomes and summaries; update embedding pipeline to include action results.
5. Provide optional hooks to notify Letta or trigger ingestion scripts.
6. Add integration tests covering HTTP success/failure and script execution scenarios.
7. Update documentation with usage examples and security guidance.
