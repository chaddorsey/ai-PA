## Requirements
- Dockerized FastAPI application with APScheduler job runner.
- SQLAlchemy models/migrations for jobs, triggers, executions, metadata, embeddings.
- REST endpoints for create/read/update/delete/list jobs and immediate trigger operations.
- Embedding generation pipeline for text metadata using local sentence-transformer (pgvector storage).
- Unit/integration tests covering scheduler behavior and persistence.
- Structured logging, type hints, and docstrings throughout codebase.

## Implementation Plan
1. Scaffold FastAPI project structure with dependency injection and configuration handling.
2. Implement SQLAlchemy models and Alembic migrations per schema from Task 19-1.
3. Integrate APScheduler with database job store; implement catch-up and idempotency mechanisms.
4. Build REST routes with Pydantic models enforcing validation, error responses, and logging.
5. Integrate embedding generation pipeline, storing vectors alongside textual metadata.
6. Write tests using pytest (FastAPI TestClient) and ensure coverage for CRUD, scheduling, and persistence.
7. Containerize the service with Dockerfile and ensure Compose compatibility.
