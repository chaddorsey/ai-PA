# PA Web UI

Web-based chat interface for the Personal Assistant ecosystem.

## Features

- Real-time chat with Letta agents
- Agent selection dropdown
- Memory block dashboard
- File upload support
- Streaming responses via SSE

## Quick Start

```bash
# Start with Docker Compose
docker-compose up -d pa-web-ui

# Or run locally
cd pa-web-ui
pip install -r requirements.txt
python app.py
```

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| PA_ROUTING_HANDLER_URL | Routing handler URL | http://pa-routing-handler:5201 |
| LETTA_BASE_URL | Letta server URL | http://letta:8283 |
| SESSION_TIMEOUT_MINUTES | Session expiry | 60 |
| ENABLE_FILE_UPLOAD | Enable uploads | true |
| MAX_FILE_SIZE_MB | Max upload size | 10 |

## Endpoints

- `GET /` - Main UI
- `GET /health` - Health check
- `POST /stream` - SSE message streaming
- `GET /api/agents` - List agents
- `GET /api/agents/{id}/memory` - Agent memory
- `POST /api/upload` - File upload

## External Access

Available at: https://pa.cd-ai-pa.work
```

### 2. PA Routing Handler README

```markdown
# PA Routing Handler

Message routing service for the PA ecosystem.

## Features

- Simple pattern-based routing (Phase 1)
- Agent selection by keyword
- Routing decision logging
- Extensible for DSPy (Phase 2)

## Quick Start

```bash
# Start with Docker Compose
docker-compose up -d pa-routing-handler

# Or run locally
cd pa-routing-handler
poetry install
poetry run uvicorn pa_routing.main:app --reload
```

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| LETTA_BASE_URL | Letta server URL | http://letta:8283 |
| PA_ROUTING_DEFAULT_AGENT_ID | Default agent | - |
| PA_ROUTING_POSTGRES_URL | Database URL | - |
| PA_ROUTING_ENABLE_DSPY_ROUTING | Enable DSPy | false |

## API Endpoints

- `POST /v1/route` - Route message to agent
- `GET /v1/agents` - List routing rules
- `GET /health` - Health check

## Routing Logic

1. If `agent_id` specified → use that agent
2. If message contains task keywords → task agent
3. If message contains calendar keywords → calendar agent
4. Otherwise → default agent
```

# PA Web UI Troubleshooting

## Common Issues

### Service won't start
1. Check Docker logs: `docker-compose logs pa-web-ui`
2. Verify port 5200 not in use
3. Check environment variables in .env

### Can't connect to routing handler
1. Verify both services on pa-internal network
2. Check routing handler health: `curl http://localhost:5201/health`
3. Verify PA_ROUTING_HANDLER_URL correct

### SSE streaming not working
1. Check browser console for errors
2. Verify CORS headers present
3. Test with curl: `curl -N http://localhost:5200/stream`

### Letta connection failed
1. Verify Letta service running
2. Check LETTA_BASE_URL environment variable
3. Test Letta health: `curl http://localhost:8283/v1/health`

### File upload fails
1. Check file size (max 10MB)
2. Verify file type allowed
3. Check server logs for errors
```
