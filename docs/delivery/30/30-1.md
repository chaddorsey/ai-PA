## Implementation Plan

### 1. Directory Structure

```
ai-PA/
├── pa-web-ui/
│   ├── Dockerfile
│   ├── requirements.txt
│   ├── app.py
│   ├── static/
│   │   ├── css/
│   │   └── js/
│   └── templates/
│
└── pa-routing-handler/
    ├── Dockerfile
    ├── pyproject.toml
    ├── requirements.txt
    └── src/pa_routing/
        ├── __init__.py
        ├── main.py
        └── settings.py
```

### 2. Dockerfile Pattern (pa-web-ui)

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 5200
CMD ["python", "app.py"]
```

### 3. Docker Compose Configuration

Add to `docker-compose.yml`:
- `pa-web-ui` service on port 5200
- `pa-routing-handler` service on port 5201
- Both on `pa-internal` network
- Health checks for both services
- Environment variable references

### 4. Environment Variables

Add to `.env`:
```
PA_ROUTING_HANDLER_URL=http://pa-routing-handler:5201
PA_WEB_DEFAULT_AGENT_ID=${LETTA_AGENT_ID}
```
