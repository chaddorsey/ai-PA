## Requirements

1. Add route for `pa.cd-ai-pa.work` to Cloudflare tunnel config
2. Test external access via HTTPS
3. Verify SSL/TLS working correctly
4. Document the access URL
5. Ensure no conflicts with existing routes

## Implementation Plan

### 1. Update Cloudflare Tunnel Config

Location: `~/.cloudflared/config.yml`

```yaml
tunnel: <tunnel-id>
credentials-file: /path/to/credentials.json

ingress:
  # Existing routes
  - hostname: letta.cd-ai-pa.work
    service: http://letta:8283
  - hostname: webui.cd-ai-pa.work
    service: http://open-webui:8080
  - hostname: n8n.cd-ai-pa.work
    service: http://n8n:5678

  # New PA Web UI route
  - hostname: pa.cd-ai-pa.work
    service: http://pa-web-ui:5200

  # Catch-all
  - service: http_status:404
```

### 2. DNS Configuration

If not using Cloudflare DNS auto-management:
- Add CNAME record: `pa.cd-ai-pa.work` → `<tunnel-id>.cfargotunnel.com`

### 3. Restart Tunnel

```bash
# If running as Docker service
docker-compose restart cloudflare-tunnel

# Or restart cloudflared process
cloudflared tunnel run
```

### 4. Verify Access

```bash
# Test external access
curl https://pa.cd-ai-pa.work/health

# Test from browser
# Navigate to https://pa.cd-ai-pa.work
```
