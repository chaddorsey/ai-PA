## Description

Implement tiered routing logic that selects the appropriate Letta agent based on message content, with domain keywords taking precedence over action keywords. Includes SUMMARY line parsing for session context tracking.

## Design Decisions

| Decision | Approach | Rationale |
|----------|----------|-----------|
| **Precedence** | Domain words > Action words | "Meeting" beats "create" - domain is more specific |
| **High-confidence triggers** | Explicit domain names | "Slack", "Jira", "Calendar", "Task", "OmniFocus" |
| **Conflict resolution** | First domain match wins | Evaluated in priority order |
| **Multi-intent** | Route to main agent | Complex decomposition deferred to Phase 2 (DSPy) |
| **Negative patterns** | Deferred | Not enough data yet for Phase 1 |
| **Semantic fallback** | Phase 1.5 enhancement | `sentence-transformers` for edge cases |

## Requirements

1. Implement agent selection with explicit `agent_id` pass-through
2. **Implement tiered keyword matching (domain → action → default)**
3. **Domain keywords take precedence over action keywords**
4. Implement default fallback to main assistant
5. Log routing decisions to database
6. Return routing reason in response
7. **Parse SUMMARY lines from agent responses for context tracking**
8. **Provide fallback summary extraction when agents don't comply**
9. **[Phase 1.5] Optional semantic embedding fallback**

## Implementation Plan

### 1. Routing Pipeline Overview

```
┌─────────────────────────────────────────────────────────────┐
│                    Tiered Routing Pipeline                  │
├─────────────────────────────────────────────────────────────┤
│ Tier 1: Explicit agent_id?           → Use it       (1.0)   │
│ Tier 2: Domain keyword match?        → Route        (0.9)   │
│         (Slack, Jira, Calendar, Task, OmniFocus...)         │
│ Tier 3: Action keyword match?        → Route        (0.7)   │
│         (schedule, remind, post, send...)                   │
│ Tier 4: [Phase 1.5] Semantic match?  → Route     (0.6-0.8)  │
│ Tier 5: Default                      → Main agent   (0.5)   │
└─────────────────────────────────────────────────────────────┘
```

### 2. Agent Selector Service (Tiered)

```python
# src/pa_routing/services/agent_selector.py
import re
from typing import Optional, Tuple
from dataclasses import dataclass

@dataclass
class RoutingResult:
    agent_id: str
    agent_name: str
    reason: str
    confidence: float
    tier: int

# Agent mapping (move to config/env later)
AGENT_MAP = {
    "task": "agent-dd15479e-6543-400e-8463-b2a48b13cd4a",
    "calendar": "agent-e28c6c16-7dbe-42dd-bbae-1e7830be8218",
    "slack": "agent-slack-placeholder",
    "documents": "agent-docs-placeholder",
    "pulse": "agent-6eb765bf-7268-4f6d-a380-c527c9c53000",
}

AGENT_NAMES = {
    "task": "Task Agent",
    "calendar": "Calendar Agent",
    "slack": "Slack Agent",
    "documents": "Documents Agent",
    "pulse": "Pulse Agent",
}

# Tier 2: Domain keywords - HIGH confidence (0.9)
# These are explicit product/service names that unambiguously indicate intent
DOMAIN_KEYWORDS = {
    "calendar": [
        r"\bcalendar\b", r"\bmeeting\b", r"\bmeetings\b", r"\bcalendly\b",
        r"\bgoogle\s*calendar\b", r"\bgcal\b", r"\bical\b",
    ],
    "task": [
        r"\btask\b", r"\btasks\b", r"\bomnifocus\b", r"\btodo\b", r"\bto-do\b",
        r"\bjira\b", r"\bticket\b", r"\btickets\b",
    ],
    "slack": [
        r"\bslack\b", r"\bchannel\b", r"\bdm\b", r"\bdirect\s*message\b",
    ],
    "documents": [
        r"\bdocument\b", r"\bdocuments\b", r"\bdocs\b", r"\bgoogle\s*docs\b",
        r"\bdrive\b", r"\bfile\b", r"\bfiles\b", r"\bfolder\b",
    ],
    "pulse": [
        r"\bpulse\b", r"\bmemory\b", r"\bremember\b", r"\brecall\b",
    ],
}

# Tier 3: Action keywords - MEDIUM confidence (0.7)
# These suggest intent but are less specific than domain keywords
# Domain keywords take precedence when both match
ACTION_KEYWORDS = {
    "calendar": [
        r"\bschedule\b", r"\bbook\b", r"\bavailability\b", r"\bfree\s*time\b",
        r"\bappointment\b", r"\bcall\b", r"\bconference\b",
    ],
    "task": [
        r"\bremind\b", r"\breminder\b", r"\bfollow\s*up\b",
        # Note: "create" and "add" are too ambiguous - could be calendar, doc, etc.
    ],
    "slack": [
        r"\bpost\b", r"\bsend\s*message\b", r"\bnotify\b",
    ],
    "documents": [
        r"\bwrite\b", r"\bdraft\b", r"\bedit\b", r"\bupdate\s*doc\b",
    ],
}


class TieredAgentSelector:
    """
    Tiered routing with domain keywords taking precedence over action keywords.
    """

    def __init__(self, default_agent_id: str, semantic_router=None):
        self.default_agent_id = default_agent_id
        self.semantic_router = semantic_router  # Phase 1.5: optional

        # Pre-compile all patterns for performance
        self._domain_patterns = self._compile_patterns(DOMAIN_KEYWORDS)
        self._action_patterns = self._compile_patterns(ACTION_KEYWORDS)

    def _compile_patterns(self, keyword_dict: dict) -> dict:
        """Pre-compile regex patterns for each domain."""
        return {
            domain: [re.compile(p, re.IGNORECASE) for p in patterns]
            for domain, patterns in keyword_dict.items()
        }

    def select(
        self,
        message: str,
        explicit_agent_id: Optional[str] = None
    ) -> Tuple[str, str, float]:
        """
        Route message through tiered pipeline.
        Returns: (agent_id, routing_reason, confidence)
        """
        result = self._select_detailed(message, explicit_agent_id)
        return result.agent_id, result.reason, result.confidence

    def _select_detailed(
        self,
        message: str,
        explicit_agent_id: Optional[str] = None
    ) -> RoutingResult:
        """Full routing with detailed result."""

        # Tier 1: Explicit agent selection (confidence: 1.0)
        if explicit_agent_id:
            return RoutingResult(
                agent_id=explicit_agent_id,
                agent_name="User Selected",
                reason="User specified agent",
                confidence=1.0,
                tier=1
            )

        # Tier 2: Domain keyword match (confidence: 0.9)
        domain_match = self._match_keywords(message, self._domain_patterns)
        if domain_match:
            return RoutingResult(
                agent_id=AGENT_MAP.get(domain_match, self.default_agent_id),
                agent_name=AGENT_NAMES.get(domain_match, domain_match),
                reason=f"Domain keyword: {domain_match}",
                confidence=0.9,
                tier=2
            )

        # Tier 3: Action keyword match (confidence: 0.7)
        action_match = self._match_keywords(message, self._action_patterns)
        if action_match:
            return RoutingResult(
                agent_id=AGENT_MAP.get(action_match, self.default_agent_id),
                agent_name=AGENT_NAMES.get(action_match, action_match),
                reason=f"Action keyword: {action_match}",
                confidence=0.7,
                tier=3
            )

        # Tier 4: Semantic embedding fallback (Phase 1.5)
        if self.semantic_router:
            semantic_result = self.semantic_router.route(message)
            if semantic_result and semantic_result.confidence >= 0.6:
                return RoutingResult(
                    agent_id=AGENT_MAP.get(semantic_result.domain, self.default_agent_id),
                    agent_name=AGENT_NAMES.get(semantic_result.domain, semantic_result.domain),
                    reason=f"Semantic match: {semantic_result.domain}",
                    confidence=semantic_result.confidence,
                    tier=4
                )

        # Tier 5: Default fallback (confidence: 0.5)
        return RoutingResult(
            agent_id=self.default_agent_id,
            agent_name="Main Agent",
            reason="Default fallback",
            confidence=0.5,
            tier=5
        )

    def _match_keywords(self, message: str, pattern_dict: dict) -> Optional[str]:
        """
        Match message against keyword patterns.
        Returns first matching domain or None.
        """
        for domain, patterns in pattern_dict.items():
            for pattern in patterns:
                if pattern.search(message):
                    return domain
        return None
```

### 3. [Phase 1.5] Semantic Router (Optional Enhancement)

```python
# src/pa_routing/services/semantic_router.py
from dataclasses import dataclass
from typing import Optional
import numpy as np

@dataclass
class SemanticResult:
    domain: str
    confidence: float

class SemanticRouter:
    """
    Sentence embedding-based routing for edge cases.
    Uses sentence-transformers (~80MB model, ~10ms/query).

    Only instantiate if Phase 1.5 is enabled.
    """

    # Exemplar phrases for each domain - used to compute domain centroids
    DOMAIN_EXEMPLARS = {
        "calendar": [
            "schedule a meeting",
            "book a time",
            "check my availability",
            "when am I free",
            "set up a call",
            "find a time that works",
        ],
        "task": [
            "create a task",
            "add to my todo list",
            "remind me to",
            "add to omnifocus",
            "create a follow-up item",
        ],
        "slack": [
            "send a message on slack",
            "post in the channel",
            "dm someone on slack",
            "send a slack notification",
        ],
        "documents": [
            "create a document",
            "write a doc about",
            "update the file",
            "edit the document",
        ],
    }

    def __init__(self, model_name: str = "all-MiniLM-L6-v2"):
        from sentence_transformers import SentenceTransformer
        self.model = SentenceTransformer(model_name)
        self._domain_centroids = self._compute_centroids()

    def _compute_centroids(self) -> dict:
        """Pre-compute centroid embeddings for each domain."""
        centroids = {}
        for domain, exemplars in self.DOMAIN_EXEMPLARS.items():
            embeddings = self.model.encode(exemplars)
            centroids[domain] = np.mean(embeddings, axis=0)
        return centroids

    def route(self, message: str) -> Optional[SemanticResult]:
        """
        Route message based on semantic similarity to domain centroids.
        Returns None if no domain exceeds minimum confidence.
        """
        query_embedding = self.model.encode(message)

        best_domain = None
        best_similarity = 0.0

        for domain, centroid in self._domain_centroids.items():
            similarity = self._cosine_similarity(query_embedding, centroid)
            if similarity > best_similarity:
                best_similarity = similarity
                best_domain = domain

        # Convert similarity to confidence (0.6-0.8 range)
        # Similarity of 0.5+ is meaningful, map to confidence
        if best_similarity >= 0.4:
            confidence = 0.6 + (best_similarity - 0.4) * 0.5  # Maps 0.4-0.8 to 0.6-0.8
            return SemanticResult(domain=best_domain, confidence=min(confidence, 0.8))

        return None

    @staticmethod
    def _cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

### 6. SUMMARY Line Parsing (Pattern 2 - Context Tracking)

Sub-agents are instructed to end responses with `SUMMARY: <action taken>`. The handler parses this to maintain session context.

```python
# src/pa_routing/services/summary_parser.py
import re
from typing import Optional

SUMMARY_PATTERN = re.compile(r"^SUMMARY:\s*(.+)$", re.MULTILINE | re.IGNORECASE)

def extract_summary(
    response_text: str,
    agent_name: str,
    tool_calls: list[str] = None
) -> str:
    """
    Extract SUMMARY line from agent response with fallback chain.

    Priority:
    1. Explicit SUMMARY: line from agent
    2. Tool name if tools were called
    3. First sentence of response, truncated
    """
    # Try explicit SUMMARY line first
    match = SUMMARY_PATTERN.search(response_text)
    if match:
        return match.group(1).strip()

    # Fallback 1: Use tool name if tools were called
    if tool_calls:
        return f"Called {tool_calls[0]}"

    # Fallback 2: First sentence, truncated
    first_line = response_text.split('\n')[0].strip()
    if len(first_line) > 80:
        return first_line[:77] + "..."
    return first_line if first_line else f"{agent_name} responded"


def clean_response_for_user(response_text: str) -> str:
    """Strip SUMMARY line from user-facing response."""
    cleaned = SUMMARY_PATTERN.sub("", response_text)
    return cleaned.strip()
```
